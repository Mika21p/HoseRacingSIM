# 主席模式：虚构地区

2026-09-20。已实现并更新本地生产构建，未发布线上。

## 使用

1. 进入“赛历与马场 → 管理地区 → 新增虚构地区”。填写名字，选择参考比赛环境，以及是否参与年度自动补马。
2. 在该地区点击“在此建立马场”，设置任意马场名与支持的草泥地。
3. 在“创办赛事”中选择该马场，设置比赛名、半月日期和原有资格、距离、格付与奖金。
4. 在“马匹 → 生成随机马群”中指定该地区，或在自建马表单中选择所属地区。推进半月即可自动报名与比赛。

新地区没有数量硬上限，也不会自动附带马场或赛事。地区管理每页显示50条。地区名当前创建后固定，不支持改名、删除；参考环境与自动补马开关可调整。默认三个地区可开关补马，参考环境保持既有规则。

## 比赛与行程

| 参考比赛环境 | 既有适性与骑手规则 |
| --- | --- |
| 日本 | 日本草地／泥地适性、所选赛道适性、日本骑手 |
| 欧洲 | 欧洲草地；泥地沿用现有欧洲规则，参考日本泥地适性；欧洲骑手 |
| 美国 | 美国草地／泥地适性、美国骑手 |

沿用参考环境是为了接入既有引擎，没有新增真实适性维度。采用欧洲或美国环境时，与现有对应赛事一样不使用日本赛道适性修正。

地区的地理身份独立：即使两个虚构地区都参考美国，彼此参赛仍需远征准备。本地比赛不增加远征等待；返乡与前往第三地复用原引擎的准备时间。AI观察按虚构地区分别记录，不直接读取真实适性。

赛事锁定与正式赛史保存当时的参考环境和地区名称。后续修改环境不改变已经锁定的届次、已完成比赛或旧评分。赛事、结果和筛选展示实际虚构地区，不显示成参考地区。

## 马群与存档

- 年度补马总数仍由全局设置决定，在已开启补马的地区间轮换分配，数量差不超过一匹。全部关闭则暂停年度补马。
- 随机生成可指定任一地区，即使它关闭了年度补马。自建马同样可选择新地区。
- 地区定义保存在世界元数据中，随自动保存、手动槽、恢复点及完整存档保留。旧世界没有地区定义时使用原来的日本、欧洲、美国，不需要重开。
- 马匹CSV的“所属地区”支持已创建的虚构地区；赛事CSV通过马场关联地区。导入前应先创建对应地区和马场，或明确映射马场；不会静默创建未知地区。
- 普通AI马的隐藏属性规则及旧游戏模式保持不变。
