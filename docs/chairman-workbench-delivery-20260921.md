# 主席工作台改版交付记录

2026-09-21。仅本地修改和验证，未部署。保留工作区原有荣誉、系列赛及其他玩法修改；未修改游戏计算规则或数据库版本；列表查询增加评分状态多选匹配。

## 功能入口对照

| 原入口 | 新入口 |
|---|---|
| 概览 | 总览 → 工作概览 |
| 赛历、重赏/后台赛事 | 赛事 → 赛历 → 赛事范围 |
| 结果与评分 | 赛事 → 赛果与评分 |
| 赛历中的马场、地区、系列赛 | 赛事 → 各自独立页面 |
| 马匹 | 马匹 → 马匹档案 |
| 繁殖中的多排标签 | 马匹 → 基础血统库、繁殖群、待用马、年度配种、幼驹、繁殖榜单 |
| 年度奖项、排行榜 | 荣誉 → 年度奖项、评分与奖金榜 |
| 殿堂、评议会 | 荣誉 → 殿堂、评议会 |
| 设置里的规则、备份、存储 | 管理 → 世界规则、游戏与备份、存储信息 |
| 手机快进、退出 | 顶部 → 游戏操作 |

桌面为 200px 分组侧栏；窄屏为五组底部导航与“切换页面”。同组保留最近访问页面。长列表滚动时，顶部时间旁持续显示当前页面。

## 交互变化

- 搜索、多选、排序、首字母、荣誉等条件全部在“应用筛选”后生效。“重置条件”和移除条件仅修改待应用内容。
- 未应用内容保留在当前会话，按世界、页面及详情对象隔离；已应用条件使用原有界面偏好保存。繁殖各页面的已应用条件分别保留。
- 多选改为面板内连续勾选；搜索 Enter 应用全部条件，输入法选词 Enter 不提交。应用后保持面板与焦点。
- 菜单脱离表格裁切区域，桌面自动翻转和避让，手机从底部展开；对象名称明确，按操作性质分组。Escape 关闭并恢复焦点。
- 工作区弹窗固定高度，仅正文滚动；简短确认保持自适应高度。详情往返保留表单、分页、展开、滚动及焦点。
- 手机主字段由各表格显式指定；展开状态绑定记录编号。繁殖空结果说明原因和下一步。
- 评分区保留原推荐、草稿与核准逻辑，使用“核准此马”“核准本场评分”；保存失败保留输入并显示重试入口。
- 只读模式可导航、筛选、查看与导出；修改入口禁用并说明原因。
- 自动进度、手动备份、恢复点分别说明。年度名单保存与年末封存使用不同文字，评议会独立管理。
