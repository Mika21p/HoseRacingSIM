# 赛场适性系统第四阶段平衡分析报告

日期：2026-09-22
结论：**验收后将草泥G由−25调整为−20；其余数值与生成权重不变。**

## 范围与方法

本报告先分析初案，再记录本轮验收决定；不修改赛场类型、草泥档位、能力计算或生成概率。

新增只读分析脚本 [analyze-track-aptitude-balance.js](../scripts/analyze-track-aptitude-balance.js)。运行：

```text
node scripts/analyze-track-aptitude-balance.js --focus
```

它以固定种子运行22种现有适性排列、六种“类型×强度”赛程，每格600次双马模拟，共79,200场类型对照；另以5,000次固定种子运行草泥A/B/C/G对照。所有类型对照固定为草地A、能力80、距离完全适配、良马场、成熟期、气性修正0、骑手70，对手为同条件的○○○马。这样只测适性差异，不把距离、重地、成长或随机生成误认为赛场适性的效果。

结果分别按三组赛程权重汇总：

1. 六类赛程机会相同的均衡赛历；
2. 当前2170场比赛库；
3. 353场已确认赛程。

双马模拟用于测量相对强弱，不代表完整多人赛、玩家选赛或未知适性下的实际胜率。普通模式能力下限另外以直接计算矩阵检查；主席模式与后台多人模拟不启用这个下限。

## 赛程样本边界

当前2170场的类型分布如下：

| 类型 | Ⅰ级 | Ⅱ级 | 合计 |
| --- | ---: | ---: | ---: |
| 瞬发 | 573 | 17 | 590 |
| 持久 | 846 | 89 | 935 |
| 消耗 | 508 | 137 | 645 |

其中353场为已确认档案，1817场为低置信度实体赛场或巡回模板。已确认组没有消耗Ⅰ，且Ⅱ级占比很高，因此它适合检查方向，不适合单独决定全局数值。当前全库赛历的持久Ⅰ占比也会让“持久◎”排列天然更常遇到可用赛事。

## 草泥适性结果

验收后的草泥差距为：A→B为5点、A→C为10点、A→G为20点。固定草地、能力80、同类型适性下，对A对手的5,000次固定种子双马对照结果为：B 22.6%、C 7.3%、G 2.9%；同档A控制组为51.4%。

G仍是明确的“应避免参赛”档位。它不是轻微短板：在无能力下限的主席模式中，能力80的草地G会落在56～64，而草地A为76～84。这个定位与草泥分离的目标相符，且20点差距仍大于单一类型适性的8点最大差距。

普通模式的60能力下限会改变低能力马的体验：能力62时C和G都会被抬到60；能力70时G全部为60；能力80时G为60～64。因此下限会压缩弱马的C/G差异，却不会让G能够同A马竞争。该交互仍是后续实战观察项；本轮已通过−20缓和高能力G马的极端压制，不再继续调整。

## Ⅰ／Ⅱ级判断

类型◎与△的差距为Ⅰ级4点、Ⅱ级8点；◎相对○的实际差距分别为2点与5点。Ⅱ级○的−1在当前全库中只影响243/2170场，平均只使○○○的类型修正下降约0.11点；在已确认组中则下降约0.69点，因为该组Ⅱ级比例异常高。

因此，○Ⅱ的−1目前既没有造成全库性的明显压制，也没有足够代表性证据证明应改为0。它保留了Ⅱ级更强的路线筛选感，建议维持。

## 建议

1. **采用草泥A 0、B −5、C −10、G −20；保留类型表和生成权重。** 当前数据没有显示○○○明显过强，也没有显示◎△△在合理择赛后缺乏价值。
2. **将G列为持续观察项。** 先在真实多人赛和普通模式生涯中记录G马的报名率、完赛率、胜率和玩家反馈；重点判断“彻底不适合该表面”是否符合玩法预期。
3. **不要按当前赛程数量调整类型公式。** 当前低置信度档案占83.7%，且确认组结构偏向Ⅱ级。应先逐步复核低置信度赛程，再决定是否需要改变全局数值或组合权重。
4. **保留分析脚本作为回归工具。** 未来修改赛程分类、草泥表、类型表或生成权重后，先重跑脚本并与本报告比较；每次只改一项。

本轮不建议引入混合类型、第四类型、地区能力或赛道特例。初步平衡验收至此完成。下一开发阶段可以按计划更新练马师评语与适性认知；若实际跑团记录显示G、Ⅱ级○或某类组合明显失衡，再回到本分析工具进行第二轮对照。
