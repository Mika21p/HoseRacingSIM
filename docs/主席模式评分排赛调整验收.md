## 操作入口

- **赛历与马场 → 重赏／后台赛事**：分别管理G1/G2/G3和OP。后台赛仍有完整出赛、奖金、休养、伤病和机器TF。
- **赛历 → 更多 → 补充年轻马准备赛**：旧世界先预览再添加；不会修改已有赛事或重复导入。
- **结果与评分 → 比赛**：选择基准马和WTR基准分，生成全场推荐，逐项调整，逐马或整场核准。
- **采用TF参考基准／生成整场默认草稿**：本场TF减固定尺度差4、5或6分；每场只确定一次。推荐不自动成为正式WTR。
- **重新生成全部推荐**：明确确认后替换草稿；核准分只有再次保存才改变。基准、草稿和手动调整保留，保存后也保留所用基准。
- **马匹 → 概况**：后台普通赛简要战绩、近期TF、目标重赏和实际下场安排。普通马能力及精确适性仍不公开。
- **榜单**：本年／历史TF、本年／历史人工WTR、旧制自动评价、本年／生涯奖金。
- **年度评价 → 取消年度覆盖**：回到最高已核准赛事WTR；没有人工赛事评价时为空，不自动回填TF。

## 当前规则与实现

### 机器评分和尺度

独立评级模块接收公开赛绩和数值着差，不读取隐藏能力、精确适性、内部最终分或压力判定。第二至第五名优先作为基准，参考最近12回合、最多5场成绩。按全场历史一致性选取基准；无适当基准时依次使用其他稳定完赛马、胜马历史、赛事历史或中位完赛马100的初始尺度。

距离换算使用1000/1200/1600/2000/2400/3200米对应3.3/3/2.5/2/1.5/1分每马身，线性插值，边界延伸限制0.5～4。原始分差前20分保留、20～40部分折半、超过40部分保留四分之一。评级分差随记录保存，后续编辑赛事不改变历史。

校准时发现：完全依赖滚动赛绩的相对评分会产生整体下移；简单给全场加一个人口中位数修正又会令封闭强组抬分。因此最终采用**80%基准推算＋20%公开同代表现标准化**。同代参考由现役马近期TF的并列中位百分位映射到100±20，再结合本场着差形成参考胜马分数。资料全空时不应用此修正。80～120仅是软参照，不是最终评分上下限；普通赛、重赏使用同一规则。该校准属于批准方案中“系统性漂移须修正”的落实。

WTR推荐使用独立人工基准和同一着差，不套用上述机器标准化，不二次扣除尺度差。年度TF、赛事WTR汇总和年度人工覆盖独立。

### 排赛

目标观察12回合、报名观察6回合，正常间隔至少3回合。条件表现、格付、奖金、等待及行程共同排序，保留10%合法探索。目标至少改善5分才替换；目标没变且前哨仍兼容时保留前哨安排。统一提案选拔，失败后继续备选，远征准备或锁定名单不随意调整。

G1挑战依据沿用方案的近期重赏前三、相近条件G1前五、OP胜利与同龄百分位等条件；二岁和三岁上半年宽松。无依据仍可报名。AI与繁殖声望在比较两套尺度时使用TF－5，正式人工WTR不被覆盖。繁殖内部后备评价和公开历史WTR分开保存，避免机器分冒充人工核准。

### 存储和兼容

- 数据库v5新增重赏结果、历史TF和旧制评价查询索引；完整存档v4，兼容v1～v3导入。
- 首次加载有写入权的旧世界时原子迁移；无写入权不改数据。
- 升级前建立独立快照恢复点，避免因为长期保留该点而积累全部逆向日志。

- 近期观察一次性从全部既有成绩建立，包括后台和隐藏成绩；正常回合增量更新。
- 比赛、AI和繁殖随机流分离；尺度差使用世界评级种子与赛事届次的确定性派生，不随打开界面重抽。

这组比较同时包含评级、排赛和年轻马准备赛历调整，不能将改善单独归因于某一项。旧版TF直接依赖内部表现，新版依据公开成绩，两列TF数字也不是同尺度准确性检验。固定水平重复比赛另有120场测试，检查无证据累积抬分。

当前仍允许未锁定安排响应新赛绩和统一选拔，因此报名变更明显多于旧版；表中统计的是下场报名变化，并非目标大赛变化。已增加目标改善5分门槛及兼容前哨保留，远征准备和锁定安排继续保护。后续应结合玩家实际赛历继续观察安排稳定性。

小马群、稀疏或极端自创赛历仍可能取消比赛；AI不会绕过年龄、性别、休养和行程限制凑满名单。TF是游戏机器参考，并非Timeform官方公式。人工WTR可以与TF差距很大，不执行强制校正。
