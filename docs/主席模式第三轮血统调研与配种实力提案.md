## 2. 数据接入方式

- 真实资料库保存来源身份、原名、别名、性别、真实出生年、父母关联、来源URL、核对日期和各字段核对状态。
- 世界内个体使用独立ID，可链接真实模板，但不把模板ID当成正在生活的马匹ID。随机马、自建马、真实模板实例共用父母关系结构。
- 地区归属与血统分开。虚构地区可使用任意基础血统；出生地区不会替代其父母遗传。
- 历史资料与游戏实例分开：现实年份不直接变成架空第1年的年龄。默认可采用“架空基础血统包”，显式建立开局前家系与世界出生年，保留原史实年份用于资料展示。
- 历史祖先作为档案节点，不能全部永久参与抽种；开局实际繁殖群单独选择并有明确年龄。历史成绩不计入游戏内奖金、G1、年度奖项或繁殖榜单。
- 三代显示由父母关系展开；同一祖先只保存一次，跨父母两边引用同一ID。原名同名个体仍须按注册身份、国家后缀及出生年核对，不仅按名字合并。
- 正式接入前补齐选定个体的三代资料；资料缺失保持未知。随机建立的始祖必须标记为架空，不能补到真实个体已知的历史父母关系中。
- 现实亲缘是事实数据；配种实力、适性和遗传倾向是游戏标定，分别存储和展示。当前清单没有为真实马匹宣称客观的1～100配种实力。

## 3. 随机马进入血统表

随机马从生成起具有稳定身份、出生年、父母关联和隐藏配种实力。三条路径均支持：

1. 由在世繁殖群正常出生，父母即真实世界内个体。
2. 外来随机马作为新的架空始祖，父母未知或由明确的架空背景家系补足。
3. 随机竞赛马退役后加入繁殖群，成为以后马匹的父母、祖父母；继续引用原赛马档案，不建立同名副本。

所有非骟马在年龄与状态允许时都可成为繁殖候选，不以G1胜利或至少一胜作为硬门槛。自动系统控制实际留种规模：优秀公开成绩提高入选和配种机会，同时保留未获胜、少出赛个体的机会。玩家可指定留种或配种；父母性别、年代和亲缘校验仍有效。

每匹母马每出生年度至多一匹正常产驹；同一父母组合也可在不同年份产生不同个体。亲缘限制按祖先关系计算，不采用“血统比例超过50%”作为唯一判据，也不把路径占比称为实测DNA比例。

## 4. 三个独立概念

| 概念 | 作用 | 默认公开性 |
| --- | --- | --- |
| 竞赛能力 | 沿用现有比赛引擎 | 普通马隐藏，自建参数可见 |
| 配种实力B，1～100 | 影响子代能力的概率分布 | 普通马隐藏，自建可填写 |
| 配种吸引力 | 决定自动配种机会 | 根据公开赛绩、子代表现及多样性计算 |

配种实力不是受胎率，不直接决定生几个孩子，也不直接作为AI抽种权重。初版采用简化生育安排，不额外叠加生育失败随机事件。

普通马真实配种实力固定在出生或首次生成时，浏览、改分和获得G1不重抽、不升级。玩家修改WTR不会改变遗传。由隐藏竞赛潜力建立轻度统计关联，实际成绩通过既有引擎间接关联；成绩直接影响的是配种吸引力。

## 5. 配种实力试验公式

建议初始版本：

`B = round(0.70 × U + 0.20 × P + 0.10 × A)`

- U：1～100均匀随机整数，每个个体独立且只抽一次。
- P：父母配种实力平均数；缺失的一方按50，双方缺失则50。
- A：出生时基础竞赛潜力映射至1～100，不使用当前疲劳、伤病、衰退后的能力，也不使用人工WTR。按当前普通生成范围62～100，试验映射为 `clamp(1 + 99 × (基础能力−62)/38, 1, 100)`；规则改版需带版本保存。
- 结果限制在1～100。70/20/10为公式权重，不等于70%遗传率或10%成绩相关系数；实际相关性需模拟测量。
- 自建马允许直接指定B。真实基准模板可有经后代数据标定的设计预设，但须标为游戏值，数据不足采用中性先验；不把所有知名马统一设成90以上。

计算顺序：父母B → 生成子代竞赛参数 → 用子代出生能力和独立随机数生成其B，不循环计算。亲本为未知祖先时采用中性值，不追溯重抽历史个体。

## 6. 对子代的具体影响

竞赛基础能力先按现有普通模式分布生成，再加一次小幅繁殖修正：

`繁殖修正 = (父母B平均值 − 50) / 10`

| 父母平均B | 能力修正 |
| --- | ---: |
| 20 | −3 |
| 50 | 0 |
| 80 | +3 |
| 90 | +4 |

保留小数至最终能力取整，限制在既定基础能力范围内。不改变主席模式比赛时取消60有效能力保底的规则。随机能力分布仍较宽，优秀父母提高群体平均与优秀后代概率，不能保证每匹子代强。

接入时只应用一套能力质量修正：不能在真实模板的旧strengthType加成、父母能力平均加成、配种实力加成之间重复累加。

适性与成长另外继承“类型”，可从父亲倾向30%、母亲倾向30%、现有随机规则40%开始试验。以完整属性组生成后校验，避免逐字段拼出非法距离区间或矛盾的成长阶段。巅峰继承类型后重抽起止，不逐字复制。祖辈影响已经经父母传递，不额外按每位祖先叠加能力奖励。

配种实力高不会让所有适性都升到A；名门后代仍可能不适合出生地区的赛历。无需新增原引擎尚不存在的跑法适性维度。

## 7. 自动配种与玩家观察

- 抽种只用公开信息与合法资格，不直接读取隐藏B。可从60%公开声望加权、40%合资格随机探索开始试验。
- 首次留种参考本马成绩；子代逐渐出赛后，提高子代表现权重。不能只看累计奖金和最强一匹，须展示出赛子代数、获胜子代比例、每匹出赛子代奖金和评级分布。
- 少量子代时标记“样本不足”，估计向平均值收缩；普通界面显示“繁殖评价／子代表现”，不反推出精确B。
- 对单一种牡马配种份额设置多样性约束，并在候选不足时明确补充外来始祖。随机探索必须涵盖低声望留种马，不能先全部淘汰再声称有探索。
- 三代血统、子代分页列表、母父贡献可查询；血统相关列表与创作导出继续隐藏普通马真实能力及B，自建马例外。
- 血统家族分享包应包含必要祖先并整体重映射ID，不能把外部编号误接本地同编号马。未做完整家族包前，跨世界父母引用应明确拒绝或要求映射。

## 8. 开发前验证与边界

1. 多组固定种子、至少20～30年：能力均值与高分尾部是否膨胀、随机家系是否被挤出、亲缘集中程度、各地区供马是否充足。
2. 同条件大样本对比低／中／高B：后代均值有差异，但分布充分重叠；弱竞赛马可以产出优秀后代。
3. 测量竞赛能力、实际赛绩、B之间实际相关性，不能将公式系数宣称为统计结论。
4. 检查父母双边贡献、重复祖先、年代、性别、同母同年限额，以及自建马后代隐藏信息。
5. 旧存档新增B必须一次性、可重放，不改变已存在竞赛属性、已完成结果和已存比赛随机流。升级时不伪造过去配种。
6. 配种、出生、出道、繁殖退役均按明确年历记录，并纳入事务、恢复点和完整存档。手工工具不绕过数据一致性。

本次只保存调研和方案，尚未实现繁殖模块，也未通过长期数值校准。下一步正式第三轮方案需确定开局繁殖群、年度留种规模、亲缘禁配范围及繁殖退役规则。
