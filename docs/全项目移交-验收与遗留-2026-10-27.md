## 1. 如何理解“通过”

| 证据类型 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 本轮源码、脚本和 Git 核对 | 入口、文件、分支及当前调用关系可定位 | 不证明游戏能运行或所有行为正确 |
| Node 单元/回归测试 | 报告对应版本的结构和已写断言成立 | 不证明史实准确、UI 可用或长测平衡 |
| 构建 | 报告对应版本可生成 dist、索引/打包约束成立 | 不证明已上线或浏览器资源全部加载 |
| 浏览器流程 | 指定浏览器、窗口、路径可完成 | 不代表所有存档、路线或设备通过 |
| 长期/配对模拟 | 指定种子、世界组合、繁殖开关、年数、正式赛事分母下的表现 | 不可跨场景当作因果对照或全项目联合验收 |
| 历史文案审阅与事实核查 | 报告列出的文本及事实检查范围 | 不表示全局史实库或后续改稿自动核实 |

旧交接中的 417 项通过、主线年龄层线的 421 项通过等均是当时记录，不是当前剧情工作区的新结果。当前 `npm test` 是 `npm run test:quick` 的别名，不包含所有长期命令。
