# 赛场适性系统第四阶段平衡研究计划

更新时间：2026-09-22
状态：已完成；验收后仅将草泥G由−25调整为−20

## 目标

在不增加新的赛场类型、马匹能力值或赛道例外规则的前提下，确定首发的草泥适性修正、赛场类型修正和马匹组合生成权重。

本阶段要回答四个问题：

1. A／B／C／G的差距是否让草泥短板有意义，同时仍保留可参赛空间。
2. ◎△△专精马能否通过合适赛程取得明确价值，而○○○不会在大多数赛历中天然最优。
3. Ⅰ／Ⅱ能否产生可感知的路线差异，且Ⅱ级○的−1不会造成难以理解的普遍损失。
4. 修正与距离、重地、成熟、气性、疲劳及普通模式的60能力下限叠加后，是否出现明显失真。

不在本阶段实现练马师评语、未知适性、血统遗传、天气动态分类或新的特殊赛道机制。

## 赛程基线与解释边界

截至准备时，比赛库为2170场，已全部解析到赛程档案。按赛事计的类型分布为：

| 类型 | Ⅰ级 | Ⅱ级 | 合计 |
| --- | ---: | ---: | ---: |
| 瞬发 | 573 | 17 | 590 |
| 持久 | 846 | 89 | 935 |
| 消耗 | 508 | 137 | 645 |

其中353场为已确认档案，1817场为低置信度实体赛场或巡回模板。因此实测必须分别报告：

1. **均衡赛历**：六种“类型×强度”机会相同，用来判断规则本身。
2. **当前全库赛历**：保留2170场实际权重，用来判断当前可玩体验。
3. **已确认赛程组**：只使用353场已确认档案，用来避免低置信度模板主导结论。

低置信度档案可以参与体验测试，但不能单独成为调高或调低全局数值的依据。

## 建议的研究步骤

### 1. 建立可复现的对照工具

新增仅供开发使用的平衡脚本和测试夹具。输入固定随机种子、马匹组合、草泥档位、赛程集合和其他修正开关；输出原始能力修正与重复模拟结果。工具不得写入玩家存档，也不得修改比赛库。

首轮应覆盖：

- 七种现有类型组合及全部排列；
- 草地、泥地各A／B／C／G；
- 六种赛程类型强度；
- 同能力对决，以及相差2、5、10点基础能力的对决；
- 普通模式能力下限开启／关闭、主席模式无下限两种环境。

### 2. 先验证修正表，再跑比赛

直接计算所有“马匹档位×赛程档案”组合，检查最大、最小和平均修正，确认计算只在赛前应用一次。随后使用固定种子做成对模拟：同一批参赛马、同一赛程和同一随机流，只替换一种适性组合或一项草泥档位。

首轮不以单场胜负作判断。每个对照至少跨多个固定种子，报告样本量、种子范围、胜率、平均名次、中位名次、有效参赛次数和能力修正分布。

### 3. 判断专精与泛用的取舍

重点比较以下组合：

- ○○△与◎△△：普通泛用和普通专精是否各有可用赛历；
- ◎○△与○○○：部分泛用是否仍值得培养；
- ○○○与◎○○、◎◎△：高稀有组合的收益是否与出现率相称；
- ◎◎○：是否仅在正确择赛时突出，而非无条件压制其他组合。

比较必须区分“随机参赛”和“知道真实适性后的理想择赛”。后者只作为理论上限；实际玩法结论应以可见信息或手动合理选赛为准。

### 4. 只比较少量可解释的候选表

第一轮保留初案作为基线，仅增加一个候选：将Ⅱ级○从−1改为0，其余不变。只有在结果显示草泥G、Ⅱ级差距或生成权重存在明确问题时，才提出第二轮候选；每次只改变一张表或一组权重。

不通过为少数赛场增加新类型、混合类型或专用补正解决平衡问题。

### 5. 输出结论并决定是否改数值

报告应给出：保留或修改的修正表、组合权重建议、证据、未解决风险和需要人工复核的赛程分类。若无显著失衡，结论可以是保留现有初案，不为产生改动而改动。

数值变动后，更新集中表、生成器和断言，再重新运行快速回归、赛程审计和生产构建。

## 完成标准

- 有可重复执行的平衡脚本与针对性测试。
- 三组赛历都提供可读的结果，不把赛程数量不均衡误认为马匹组合强弱。
- 对○○○是否过强、◎△△是否过弱、○Ⅱ是否应为−1、草泥G是否过重分别给出结论。
- 给出首发数值与生成权重，或明确保留当前数值的依据。
- 不改动第五阶段的练马师评语和认知规则。
