# 主席模式 NPC 排赛：阶段 1 实现与验收

日期：2026-09-28

状态：阶段 1 实现与专项验收完成，已写入本地工作区，未发布；全地区赛事覆盖退步保留为后续必修问题。

对应 [分阶段规划](主席模式NPC排赛优化分阶段开发与验收规划-2026-09-28.md) 的“排赛基础修正”。本轮主要作用于新版现实参考／空白世界，旧版排赛模块未改动。

## 1. 实现内容

### 补人数只调整相近选择

- 从当前有容量的候选中确定基础效用最高者。
- 只有效用差不超过 1、草泥一致、距离差不超过 400 米、公开条件估计不明显下降的候选，才可能获得人数调整。
- 相对于首选，命名赛事人数调整最多增加 0.75，补充赛最多增加 0.5；首选更缺人时不会反向鼓励去更拥挤的替代赛事。
- 不因补人数开启跨交通组行程，不把具有不利条件证据的路线作为补位去处。
- 不把马从其当前最佳目标抽走，也不靠人数奖励制造与显示目标不足三回合间隔的替代报名。
- 二次补足两匹时执行相同意愿限制，并检查相对原始可选首选的累计效用损失，防止连续转派逐步突破限额。
- 仍保留满额后的合法备选，不要求所有马必须报名同一场 G1。

这里的数字是阶段 1 的实现参数，不是声望权重。级别基础分、奖金行为、远征运输回合、开局人口和年度新马目标均未调整。

### 合并保留距离与举办条件

补充赛合并要求同日期、同地区、同马场与赛道配置、同草泥地、同距离、同级别及显示格付、同年龄和性别规则。还要满足容量、参赛资格、候选可接受性和累计效用损失限制。

已锁定或包含已承诺参赛马的名单继续保护。不再发生把 1200 米报名批量合并为 2400 米的情况。

### 用近期公开证据认识条件

- 观察最近 12 回合、最多 8 条有效成绩；排除退赛、非有限 TF、无效距离／场地、未来和过期记录及无效名次。
- 以中位数描述表现，降低单次异常或失常影响；按同草泥、同距离类别取样，必要时参考 400 米内的邻近距离。
- 保留样本数量、置信度、是否未知条件、是否有不利证据，供审计解释。
- 样本少时向该马自己的公开总体表现收缩，不让未知条件因为固定 100 分而自动优于已知的较弱表现。
- 对已形成可靠路线的马，减少缺乏依据的换草泥和大幅换距离；存在可靠备选时，每四次出赛周期保留一个可尝试当地非重赏路线的窗口。
- 缺少可靠候选时仍可考虑本地替代机会，但不能用探索或补位为无依据的跨交通组行程开路。
- 已赢过分站的连冠追逐属于明确参赛理由，下一站不受普通未知条件探索门槛阻挡；资格、伤病、休养和运输约束仍然生效。
- 未读取隐藏能力、精确草泥适性或赛道适性来替代公开判断。

### 固定偏好与保留合理报名

- 偏好由世界种子、年份、马匹和赛事届次确定，同状态重新规划不会重新摇骰子。
- 偏好扰动缩小到 0～0.5；报名选拔同分顺序及探索窗口也固定。
- 合法、尚有容量且与当前最佳可选方案差距不超过 1 的旧报名优先保留。
- 新证据、失去资格、伤病、容量或赛历变化仍可触发重新安排。
- 新版排赛不再消耗 `aiRngState` 来重抽每个候选；保存与重载不改变偏好。旧版世界的随机流程保持原样。
- 不增加必须迁移的存档字段；已开始准备和锁定报名优先于新选择。

这只是阶段 1 的选择稳定性，不等于阶段 2 的半年目标、前哨与主动休整已经完整实现。

## 2. 审计工具修正

本轮首次出现取消场次后，发现阶段 0 工具通过导出函数包装捕获后续规划，但创建函数直接调用内部排赛，因此漏掉了初始规划的诊断数据。

修正方式是在世界创建时提供默认关闭的诊断工厂，在第一次真实排赛前接入观察。没有通过“创建后再排一次”补日志，避免对旧规则重复消耗随机数。

- 新增创建过程审计开关一致性测试。
- 检查点恢复测试要求两次推进对应两份规划统计，防止重新漏掉首回合。
- 更新取消归因，明确记录条件证据筛选，而不是把这类筛选混称运输或休养限制。
- 旧报名保留造成的选择，不再计入“缺人奖励改变选择”。
- 使用修正后的同一工具重新运行修改前排赛和阶段 1 排赛，作为正式对照。

修改前排赛保存在 `artifacts/chairman-world-before-scheduling-stage1.js`；用于重跑的 `artifacts/chairman-world-stage0-audit-create.js` 只为该副本添加了初次创建的诊断入口，没有改动决策。报告记录替代排赛源码路径与哈希，不能把它误当成当前排赛版本。

阶段 0 原报告的世界结果仍可作为历史事实，但其部分规划累计统计漏掉首回合。本轮对照统一使用修正工具生成的数据，不混用旧计数。

## 3. 场景与功能验收

| 场景 | 阶段 1 要求／结果 |
|---|---|
| G1 已有 8 匹，G3 空场，4 匹最高评分马尚未报名 | 4 匹留在合适的 G1 |
| 本土合适 G1 与海外空场 G1 | 不因人数奖励把这 4 匹马送出国 |
| 1200 米与 2400 米各有 6 匹适合的马 | 保持 6／6，不跨距离合并 |
| 近期 OP 与两回合后的显示目标冲突 | 不因冷门奖励产生原场景中的 4 次冲突 |
| 未试条件与已知 TF 80 的路线 | 未知估计沿用该马表现并体现不确定性，不跳到 100 |
| 过期、未来、退赛、空 TF、无效名次以及单次极端表现 | 排除无效记录；中位数不会被单个极端值主导 |
| 本地有限探索／无依据跨交通组尝试 | 前者仍可成为候选，后者被排除 |
| 已有连冠进度，下一站是新距离或海外场地 | 保留下一站候选；伤病时不能强行参加 |
| 目标容量只有 2，另有合法 G3 | 前两匹进入目标，其余可进入合法备选 |
| 已锁定安排 | 保留原报名和准备信息 |
| 修改隐藏能力及精确适性 | 不改变选赛结果 |
| 所有马休养或行程不可达 | 不强行补位，可以取消 |
| 同状态保存／重载／重复规划 | 完整世界状态相同 |

另对默认 1,000 匹日本世界做了重复规划检查。三个旧世界测试的“强制补足两匹”预期按新需求更新为“保护锁定者、允许自愿加入、不能为了小场强迫其他马改签”，没有删除锁定和资格检查。

## 4. 同配置首年对照

正式对照使用种子 123、默认人口、日本与全地区组合，各运行修改前和修改后一个完整首年及一次年末结算。四条运行顺序执行，性能采样期间不并行运行常规测试。

| 指标 | 日本：修改前 → 阶段 1 | 全地区：修改前 → 阶段 1 |
|---|---|---|
| 命名赛事开赛数 | 190/190（100.00%） → 172/190（90.53%） | 529/529（100.00%） → 482/529（91.12%） |
| 重赏达到 6 匹场数 | 126/133 → 129/133 | 355/367 → 343/367 |
| 改签／可改签机会 | 13061/15771（82.82%） → 4509/15442（29.20%） | 16982/20492（82.87%） → 12349/27190（45.42%） |
| 跨距离合并次数 | 640 → 0 | 400 → 0 |
| 人数奖励改变选择次数 | 10026 → 759 | 20043 → 1388 |
| 海外出赛／总出赛 | 0/5526（0.00%） → 0/5700（0.00%） | 7570/16845（44.94%） → 6890/17408（39.58%） |
| 跨交通组出赛占比 | 0.00% → 0.00% | 36.91% → 34.28% |

改签和奖励计数是各回合累计事件，不是去重马匹数；重赏统计包含未开赛赛事，不能只对已举办赛事计算。海外按所属地区判断，跨交通组另列。

**改善与退步同时存在。** 日本取消 18 场（16 场 OP、2 场 G3），均有合法候选但最终未被选择。全地区取消 47 场（35 场 OP、7 场 G3、5 场 G1）；其中 35 场归为分配／赛程选择，12 场在休养、运输或已有承诺过滤后缺少候选。该归因是观察到的筛选过程，不等于反事实证明。

全地区未开赛的 5 场 G1 均在美国：斯宾纳韦锦标、德尔马初登场锦标、香槟锦标、费烈兹锦标、育马者未来锦标，各仅 1 匹报名，候选数为 2～4 匹。阶段 2 必须纳入这些场景，检查目标冲突、当地幼马路线和同档赛事之间的分配，不能只看全球平均开赛率。

日本重赏达到 6 匹的场数改善，但全地区由 355 降到 343。阶段 1 的行为修正通过，不代表整体验收通过；重要赛事覆盖下降是明确保留的后续问题，不能用增加默认人口或恢复强制补位掩盖。

## 5. 性能处理

初版固定偏好逐候选计算长字符串哈希，CPU 采样确认哈希为主要热点，导致日本首年正常半月 P95 高于预期。

随后将马匹年度种子和赛事种子分别预计算，用整数混合生成候选偏好；并把补人数条件中的廉价排除放到地区查询之前。没有通过放宽性能验收线处理该问题。

| 正常半月计算 | 修改前中位数 / P95 | 阶段 1 中位数 / P95 | P95 倍率 |
|---|---|---|---|
| 日本 | 204.4 / 229.0 ms | 248.4 / 285.4 ms | 1.25 |
| 全地区 | 692.7 / 823.6 ms | 835.1 / 1200.6 ms | 1.46 |

各列均为完整首年的 24 次正常推进样本。日本创建耗时 4.00 → 4.25 秒，全地区 63.68 → 62.45 秒。阶段 1 年度审计总耗时分别约 26.15、113.51 秒（不含创建，包含双跑校验与检查点读写）。两组 P95 均低于规划中 1.5 倍初始警戒线，但全地区 1.46 倍已接近该线；后续增加目标和声望逻辑时必须继续监测，不能视为没有性能成本。

这些数据来自离线规则执行，进程同时保有审计和对照对象；不代表浏览器保存耗时。创建世界涉及基础繁殖种群，首年完整运行成本应同时看创建和年度推进，不可只看单回合。

## 7. 已知边界与后续输入

- 首年单种子对照不足以说明所有种子和长期赛季的开赛率，也不能直接决定人口默认值。
- 减少强制补位后，存在合法候选却无人选择的赛事必须单独识别，不能统称为“马数不够”。
- 本轮保留原有级别基础效用；普通马如何定位、为何选择特定大赛或 OP，应在阶段 2 的目标与声望体系中进一步处理。
- 目前仅阻止人数补偿和无依据探索单独触发跨交通组出行，尚无专门的返乡计划或跨洲累计成本。
- 普通目标仍可能与实际备选不同，合法前哨也会产生这种差异；不能把所有目标不一致都判为错误。
- 阶段 4 的 95% 开赛率等指标仍需在后续机制完成后校准，不能以本轮场景通过冒充整套优化完成。
