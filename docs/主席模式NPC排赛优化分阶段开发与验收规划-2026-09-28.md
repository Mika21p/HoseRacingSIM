# 主席模式 NPC 排赛优化：分阶段开发与验收规划

日期：2026-09-28

状态更新（2026-09-29）：阶段 0～3 已完成相应开发与功能验证。阶段 4 已按用户后续要求完成探索与实验交付，**初步验收部分通过、带遗留项结项**，见 [阶段 4 结项与交接](主席模式NPC排赛阶段4结项与交接-2026-09-29.md)。人口筛选和双倍人口实验未找到合格新默认值；后续 TF 原型在小规模验证中通过评分可用性和异常参考检查，但尚未正式接入。原定人口与整体验收仍未通过，默认人口保持不变，正式接入、人口复核、兼容与性能转阶段 5；阶段 5 尚未实施。历史测试数字保留在各版本报告中，不视为当前版本重跑结果。

## 1. 本轮目标与范围

让 NPC 围绕适合自己的赛事形成连续、可解释的参赛路线；重要赛事能够吸引相应水平的马，普通赛事仍有合理马源；降低无明确目的的跨洲远征，并通过模拟确定足以支撑赛历的默认马群规模。

### 1.1 用户明确提出的需求

- 改善排赛不智能、扎堆冷门赛事、表现过于功利的问题。
- 引入赛事声望，区分同级赛事，尤其不同 G1 的吸引力。
- 现实参考赛事自带声望，玩家新建赛事可以自定义声望。
- 评估并改善海外参赛过于频繁的问题。
- 通过测试确定合理的开局默认 NPC 数量，使大部分比赛有足够参赛马。
- 给出分阶段开发和验收规划，保存到本地。

### 1.2 本文建议采用、仍需开发验证的设计

- 声望采用 0～100 整数；现实参考赛事也允许玩家在当前世界覆盖其声望。
- 以目标赛事、前哨、休整与远征计划组织报名。
- 减弱补人数对马匹决策的干预，避免补位推翻明确目标。
- 同时校准开局现役数量和每年二岁马目标。
- 第一版声望固定，不做年度自动升降；第一版使用简明的马匹发展定位，不引入完整马主性格系统。

以上是可执行的推荐方案，不应在开发报告中写成用户已逐项确认的精确规则。具体效用权重、声望档位、人口数值和统计验收阈值均须保留校准记录。

### 1.3 实施边界

- 主要改造 `worldSystemVersion === 2` 的现实参考世界和空白新世界。
- 旧版世界继续使用原有排赛身份；如需给旧版增加声望效果，另立兼容任务，不静默切换其排赛算法。
- 保留资格、年龄、性别、伤病、最低出赛间隔、运输可达性、容量及锁定承诺等约束。
- 不直接修改比赛胜负算法、TF／WTR 公式、遗传公式或历史赛果来改善排赛统计。
- NPC 主要使用公开赛绩和可观察信息，不读取隐藏真实能力或精确适性作为选赛捷径。
- 本轮实现、测试和构建以本地交付为范围；发布另行处理。

## 2. 当前基线与已确认问题

### 2.1 两套排赛不可混用结论

`js/rules/chairman.js` 的 `planEntries` 将新版世界交给 `ChairmanWorld.plan`，旧版交给 `ChairmanScheduling.plan`。

旧版已有未来 12 回合目标观察、未来 6 回合报名和目标切换门槛；新版主要观察未来 6 回合，生成目标展示后按效用分配，再进行补位与补充赛合并。因此旧版文档中的目标保护不能视为新版已经实现。

### 2.2 当前新版的关键规则

| 项目 | 当前行为 | 风险 |
|---|---|---|
| 级别吸引力 | G1=9、G2=8、G3=7、OP=4 | 同级赛事缺少荣誉差异 |
| 缺人奖励 | 非补充赛事最多加 8 | 足以压过级别、行程和马匹偏好 |
| 目标赛事 | 普通目标主要用于展示 | 目标与实际报名可能脱节 |
| 条件表现 | 按草泥地和距离类别平均 TF，未知条件按 100 | 对样本不确定性、相邻距离、举办环境认识不足 |
| 重新排赛 | 未锁定安排重新计算，含 0～3 随机项 | 同一目标缺少稳定承诺 |
| 补充赛合并 | 检查日期、地区、级别等，未要求距离相同 | 可把短途马合并到长途比赛 |
| 运输 | 同交通组 1 回合、跨组 2 回合，支持地区对覆盖 | 选赛成本较低，且没有完整远征结束计划 |
| 赛后位置 | 留在比赛地区 | 可能长期滞留海外，回国反而另付运输成本 |
| 默认人口 | 日本固定 1,000，其他按命名赛事数粗略估算 | 未充分计入赛历冲突和细分马源需求 |

当前规则中的时间单位为半个月；3 回合最低间隔相当于一个半月。运输准备与出赛间隔取较晚的可用时间，并非全部串行相加。

### 2.3 已在本次讨论中复现的场景

- 同日期、同条件的 G1 已有 8 匹锁定参赛马，G3 无人报名：额外 4 匹最高公开评分马全部选择 G3，显示目标仍是 G1。
- 6 匹短途马和 6 匹长途马具有明确不同的公开条件表现：分别选择 1200 米和 2400 米补充赛后，被合并为一场 2400 米比赛。
- 固定条件与随机种子，仅大幅提高 G3 奖金，报名结果不变。新版没有直接按奖金收益或对手强弱计算选赛效用，生涯奖金主要用于同评级分配顺序。

这些是机制复现，不是玩家存档总体统计。需要在阶段 0 中固化成可重复的行为场景。

每年二岁马目标会先计入长到二岁的幼驹，再补足不足部分；超过目标的幼驹不会被删除。因此目标数不等于固定净增长量。

## 3. 开发顺序与阶段交付

| 阶段 | 主要工作 | 交付 | 进入下一阶段的条件 |
|---|---|---|---|
| 0 | 固化基线、行为场景和统计口径 | 基线报告、可复现审计入口 | 能准确解释现有异常，具备对照能力 |
| 1 | 修复补位、合并和选赛证据问题 | 排赛基础修正 | 不合理调马场景消除，硬约束全部通过 |
| 2 | 声望资料、编辑入口与目标路线 | 声望体系、目标保护、原因展示 | 声望影响合理选择，目标与报名一致 |
| 3 | 远征计划、海外驻留与返乡 | 有起止的远征安排 | 减少无目的跨洲移动，合理国际赛事仍可参加 |
| 4 | 人口筛选、资格供给诊断与后续 TF 原型实验 | 实验结果、现有默认值保留决定、结项交接 | 已带遗留项结项；原人口指标未通过，不等同于整体验收 |
| 5 | 出道／TF 正式接入、人口联动复核、存档与浏览器验收 | 本地完整交付、人口决策、最终验收报告 | 以正式版本的办赛、规则、兼容与性能证据验收，先小规模验证 |

阶段 0～3 的对照测试保持人口不变，以识别排赛改变的真实作用。阶段 4 才调整默认人口，避免用增加马匹掩盖算法问题。阶段 2、3 可分别验收，但必须联合完成后再冻结用于人口校准的规则。

## 4. 阶段 0：基线与观察能力

### 开发内容

1. 固化规则、数据、种子、人口、年度目标、繁殖及退役设置；记录源码指纹和运行环境。
2. 将第 2.3 节的小场景保存为可重复检查，补充本土／跨洲选赛、目标前哨冲突、海外驻留等场景。
3. 扩展世界审计，记录候选被排除原因、目标与实际报名、补位前后变化、运输和驻留状态。完整调试明细仅在审计模式下开启，避免扩大普通存档。
4. 将取消原因拆成：资格马源不足、休养／运输不可达、赛历冲突、候选不愿参赛、满额落选、赛事设置变化等。允许一场记录多个限制因素，指定一致的主要归因顺序。
5. 当前默认人口运行少量完整赛季，建立旧行为对照；旧长期文件只作参考，不替代当前源码重跑。

### 验收

- 固定世界快照、规则版本和随机状态可以重现结果；审计开关不改变报名、比赛或繁殖随机流。
- 统计不遗漏第一年、取消赛事、未报名马和在海外停留但未比赛的回合。
- 调试记录能指出最高评分马为何去冷门赛事、为何被改派距离、为何出国或不回国。
- 先测算单个“世界年”的时间和内存开销，再确定长测批次；记录预计规模和检查点，不无上限扩大矩阵。

## 5. 阶段 1：排赛基础修正

### 开发内容

1. 将赛事补人数调整限制在马匹本来就认可、效用差距有限的候选之间。补位不得单独触发跨洲远征、破坏系列目标或造成明显不合适的条件转换。
2. 补充赛第一版只合并同距离且其他条件兼容的赛事；若以后支持近似距离，必须重新评估每匹马，不能仅按赛事字段粗略合并。
3. 改善公开赛绩估计：限定观察窗口、处理异常／退赛记录、标记样本量；未知条件使用带不确定性的参考，不因固定 100 分而自动优于已知路线。
4. 允许有限探索，但减少毫无依据的草泥转换和大幅跨距离尝试。不能把“一次失常”立即解释为整条路线不适合。
5. 统一随机偏好的生命周期，为下一阶段目标稳定性提供基础；同一世界状态反复触发规划，不应仅因重新抽随机数而不断改签。

### 验收

- 6 匹短途马与 6 匹长途马的补充赛场景不再错误合并。
- 冷门赛事补位不会无条件吸走已具有合理大赛目标的强马。
- 已锁定、已进入准备期的安排继续得到保护。
- 年龄、性别、资格、伤病、容量、出赛间隔、运输可达性违规数为 0。
- 合法马源不足时允许赛事取消，并能解释原因；不为维持旧开赛率恢复强制调马。

## 6. 阶段 2：赛事声望与目标路线

### 6.1 声望资料与编辑

- 建议添加 `prestige`，整数 0～100，0 是合法值，缺失值与 0 必须区分。
- 声望独立于级别和奖金，不强制规定 G2 声望一定低于 G1。
- 现实参考赛事按稳定来源 ID 配置默认值和简短赋值依据；不得以赛事名称作为唯一关联键。
- 实施资料赋值时核对权威赛事资料，记录来源和核对日期。声望分是游戏设计判断，不宣称存在统一官方声望评级。
- 对不同地区、草泥地、年龄、距离路线分别检查分布；有代表性的短途、泥地、牝马、长距离赛事不能因路线小众被整体压低。
- 自建赛事提供级别建议值，允许玩家自由填写；参考赛事允许世界内覆盖，支持恢复参考默认值。
- 修改预览、赛历／档案展示、输入校验、赛事包导入导出同步支持声望。
- 第一版不根据单届阵容自动涨跌，不改变历史比赛的声望快照。

### 6.2 目标与报名

- 建议采用未来 12 回合的目标观察，保留较短的实际报名窗口；以性能测量决定是否调整窗口长度。
- 流程为：资格与可达性 → 条件路线与证据 → 目标赛事 → 前哨／休整 → 报名选拔 → 合法备选。
- 声望主要影响值得等待和准备的目标，不能突破硬约束或抵消明显的距离／草泥不匹配。
- 根据公开表现区分积累经验、挑战升级、争夺高水平荣誉等状态；避免所有马都追逐最高声望赛事。
- 普通目标获得间隔和远征准备保护；与既有连冠系列目标统一处理，保留合理优先级。
- 只有成绩新证据、伤病、资格变化、落选、赛历编辑或足够明显的更优选择，才触发目标调整。具体门槛通过场景与模拟校准。
- 将休整作为正常选项；不要求每次合法间隔结束后立即出赛。
- UI 展示真实原因：主攻大赛、前哨、复出、探索、落选备选、远征第二站等。若改变目标，显示最新安排，不保留误导性的旧理由。

### 验收

- 相同日期、资格、地点与条件下，成熟强马对高声望目标表现出稳定偏好；以多种子比例和固定偏好场景验证，而非要求所有马作同一选择。
- 高声望长距离赛不会吸引已有充分短途证据的马无条件改线。
- 高声望目标在未来时，可选择兼容前哨或休整；不因近期冷门赛事缺人而破坏准备。
- 同一状态重复规划稳定；伤病、落选及合法赛事编辑后能够重新计划。
- 声望 0、100、空值、越界、小数、非数值均按定义处理；创建、编辑、复制、导入、导出、重载均一致。
- 参考资料更新保留玩家覆盖，已锁定届次和历史记录不被追溯改写。
- 存档加载和迁移本身不重抽比赛、繁殖或 AI 随机状态。

## 7. 阶段 3：远征、驻留与返乡

### 开发内容

1. 区分同地区、近邻跨境和跨洲远征。可复用交通组和地区对设置，但不能只因地区名字不同就视为跨洲。
2. 本土有合适路线时默认留在本土；出国需要由目标声望、系列、卫冕、国内路线缺口或明显条件优势提供理由。
3. 依据公开竞赛水平调整远征意愿，普通马不因海外空场就频繁跨洲；不得写成仅顶级马才能出国的绝对禁令。
4. 建立远征计划，包含出发地、目标地区、主目标、可选当地热身／后续赛事、结束条件和返乡意图。
5. 到达后允许合理连战；增加无后续目标、目标结束、伤后休整等退出条件，避免长期无目的漂泊。
6. 返乡必须占用真实运输准备，不瞬移、不和比赛冲突；不能为了强制返乡破坏已锁定的合理连续赛事。
7. 对连续跨洲移动设置递增的安排成本或恢复需求，具体强度以模拟确定。第一版不采用全球统一的年度出国次数硬上限。
8. 保存计划状态并处理年末、赛历变化、地区停用、归属编辑、恢复备份及存档迁移。

### 验收

- 日本马在国内存在相近合适赛事时，不因普通海外赛事缺人而专程跨洲。
- 高声望国际目标仍可吸引符合条件的强马，不能把国际赛事全部变成国内赛。
- 欧洲近邻参赛与日美欧跨洲远征呈现不同决策成本。
- 一次海外目标完成后，能够接续明确第二站或安排返乡；无计划的海外驻留不会无限延续。
- 返乡、转往第三地、伤后休整和跨年连续赛事不违反时间及锁定规则。
- 统计同时报告跨地区移动、跨交通组移动、海外出赛和海外驻留时长，不把一次驻留多场误算成多次出国。
- 在人口固定的基线对照中，无明确高价值目标的跨洲参赛减少；比例目标在阶段 0 建立基线后预先登记，不能看到结果再挑有利口径。

## 8. 阶段 4：默认马群数量与年度补充校准

### 8.1 校准原则

- 使用阶段 1～3 联合验收后的固定算法和声望资料，不能一边变算法一边宣布人口达标。
- 寻找有适度余量的合理规模，不以所有赛事满员为目标。
- 优先诊断短缺属于总量、结构、赛历冲突还是不合理排赛。必要时调整开局年龄／资格等结构，但每次变化必须单独记录和对照。
- 不能提高马匹真实能力来让报名变合理，不能单纯增加跨洲流动来救活本土赛历。
- 保留玩家手动选择人口的能力；最终新默认值只用于新世界／新增地区建议，不静默改写已有世界的人口和年度目标。

### 8.2 测试场景

正式矩阵包含 7 个单地区世界、日本＋美国、欧洲五国、全部七地区，共 10 类。阶段性筛选可先运行日本、美国、欧洲和全地区四类，再验证其余地区。

附加边界场景包括空白世界自建稀疏赛历、牝马或年龄限定密集赛期、少量泥地／长距离马源、小人口与新增赛事后的需求缺口。极端自建世界用于解释边界，不承诺任意配置都达到默认参考世界指标。

### 8.3 分轮实验

| 轮次 | 参数 | 时长与种子 | 用途 |
|---|---|---|---|
| A：数量筛选 | 当前人口的 75%、100%、125%、150%；先保持年度目标比例为四分之一 | 代表场景，3 种子，各 3 年 | 找到达标区间并发现明显结构短缺 |
| B：年度补充 | 达标区间附近的开局数量；年度目标比较开局的 20%、25%、30% | 扩展到 10 类，先短测，候选跑 10 年 | 识别退役／繁殖后的长期马源不足或膨胀 |
| C：组合定稿 | 每地区推荐的开局数量和年度目标 | 10 类，3 种子，各 10 年 | 检查同一套默认值在单地区和组合下是否成立 |
| D：留出复核 | 冻结后的最终默认值 | 2 个未用于调参的种子，10 类先跑 3 年；全地区及风险最高场景继续到 20 年 | 检验首年鲁棒性与长期稳定性 |

筛选种子建议固定为 123、43127、995173；留出种子建议为 614092、850173。若阶段 0 已用某种子调参，该种子不能再算独立留出样本。

不运行全部参数的无差别笛卡尔积。每轮根据预先定义的淘汰规则停止明显不合格候选；最终推荐组合必须完整跑完规定矩阵。若留出复核后再次调参，需要替换或追加真正未参与选择的验证种子。

每次测试报告中记录整数取整方式、各地区实际数量、年度目标、生成分布和繁殖设置。发生边界短缺时继续细化区间；不预先认定日本必须增至某个整数规模。

### 8.4 初始验收目标（建议值，阶段 0 后冻结）

用户后续修订人数标准为非 G1／低声望 G1 至少 5 匹，高声望 G1 至少 8 匹；2 匹仍只是开赛门槛。原阶段 4 报告保留当时的历史口径，新实验见双倍人口验证报告。

| 指标 | 建议目标 | 统计说明 |
|---|---|---|
| 命名赛事正常举办率 | 每个默认场景、种子、地区年度 ≥95% | 第一、二年同样验收；不只看第 3 年之后 |
| 非高声望 G1 的命名赛达到 5 匹比例 | ≥90% | 用户后续修订：含非 G1 与声望 <85 的 G1；取消和不足 5 匹均算未达标 |
| 高声望 G1 达到 8 匹比例 | ≥90% | 暂以声望 ≥85 定义；阈值随声望方案一并冻结 |
| 资格／间隔／容量／锁定违规 | 0 | 每场、每匹检查 |
| 强制不合理跨条件调马 | 0 | 阶段 1 的行为定义 |
| 首年与长期稳定性 | 分别达标 | 不允许后期平均值掩盖开局缺马 |
| 无目的跨洲、目标完成率、改签率 | 对照改善 | 具体阈值在基线后预先确定 |

小地区赛事数少时，必须列出每场缺口，不能只写平均值。没有 G1 的地区记为“不适用”。若默认源赛历存在无法合理满足的年龄／日期冲突，应明确列为赛历缺陷并提出处理，不以暗中排除赛事的方式达到指标。

命名赛事原则上以非补充赛事为范围；明确停办、尚未生效或当年按规则不应举办的届次不计入分母。按需补充赛不以全举办为目标，但要单独检查有需求的未胜利／条件马是否长期没有合理出口。

### 8.5 性能与最终决策

- 使用同一机器、同一运行环境比较算法和人口两方面开销；单项性能测量避免与重型批量任务同时争用资源。
- 报告半月计算中位数、P95、最大值，保存耗时、20 年历史体积和峰值内存。
- 同人口下建议以半月计算 P95 不超过基线 1.5 倍作为初始警戒线；如超出，必须分析和优化，不能仅改大容忍值。
- 更大人口的绝对等待时间与存档开销需做浏览器实测，并在阶段 0 根据当前设备确定体验预算。
- 从同时满足办赛、参赛合理性和性能的候选中，选择接近下限并有余量的方案；余量须由失败边界和多种子波动支持。
- 最终输出各地区“开局现役／年度二岁马目标／验证场景／主要短缺类别／性能代价”表，不只给全球总数。

## 9. 统一指标定义

为避免不同阶段统计口径漂移，审计至少固定以下定义：

| 指标 | 定义 |
|---|---|
| 开赛率 | 已完成的应举办命名赛事届次数／全部应举办命名赛事届次数 |
| 场均人数 | 同时报告含取消场次与仅完成场次两套数据，并列人数分位数 |
| 海外出赛率 | 出赛记录中比赛地区不同于马匹当时归属地区的记录数／全部出赛记录数 |
| 跨地区／跨组移动 | 按实际地点变化记录，包括返乡；区分交通组，不以马匹归属代替出发地 |
| 海外驻留 | 以半月记录实际位置，累计离开归属地区时间；与比赛次数分开 |
| 目标参赛率 | 到期目标实际参赛次数／到期承诺次数；另列伤病、资格变化、落选、赛事编辑等取消原因 |
| 改签率 | 未锁定报名变化次数／具有有效旧报名的规划机会数；首度报名和正常完赛清空不算改签 |
| 强马对决 | 使用赛前公开评分、按竞赛路线划分的领先马群，统计重要赛事聚集和相遇次数 |
| 长期无合理出赛 | 对健康、现役且存在可达合法赛事的马统计等待时间；主动目标休整单列 |
| 结构缺马 | 按地区、资格、年龄、性别限制、草泥地、距离及拥挤赛期交叉查看 |

强马识别不能读取隐藏能力，也不能用赛季结束后结果倒推当时已经知道其强弱。资格可参赛不等于值得参赛，诊断时必须分开报告。

- 所有长测支持检查点与恢复。源码或影响结果的数据变化后，旧结果只作历史对照；不能拼接不同规则指纹的年份冒充一次完整运行。
- 对中止、异常退出、漏跑种子或未覆盖场景明确记为未完成，不计入通过样本。
- 不因少数种子通过就删除失败种子；失败必须归因并修复或公开说明边界。
- 指标若需调整，记录原因、调整时间与受影响结果；正式结果使用冻结后的同一口径重算或重跑。
- 实施阶段的下一步由上述阶段条件驱动；常规修复和合法范围内的参数校准无需每次重新确认。涉及扩大玩法范围、改动历史事实或另行发布时，单独说明。

本轮完成的判定是：默认参考世界在新排赛、声望与远征规则共同作用下，既能维持大部分赛事正常举办，也能通过目标稳定、合理对决、海外活动和性能指标；并已用完整记录支持所选人口默认值。
