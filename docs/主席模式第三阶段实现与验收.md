# 主席模式第三阶段：实现与验收

日期：2026-09-20。范围为用户批准的血统库、自动繁殖与世代传承；本轮不发布线上。

## 交付与使用

国际预设新世界默认启用繁殖，仍有300匹初始竞赛马，另建立日本、欧洲、美国各约10牡30牝的基础繁殖群。初始赛马可拥有标为“开局背景”的亲缘，不补造赛绩或配种事件。空白开局不自动建群；在“繁殖 → 建立基础繁殖群”选择地区和来源包。旧世界在“繁殖 → 启用自动繁殖”后从当前年份启动，原有竞赛参数和已知亲缘不变。

繁殖入口有基础血统库、当前繁殖群、待用马、年度配种、幼驹、繁殖榜单六个视图。默认自动安排，无须逐匹配对。年度配种可以添加、替换、取消指定配对；同母替换已有指定，不重复占用。年末校验失效指定，提示玩家修正，随后统一锁定。预览复制世界计算，不消耗正式随机流。

时间为N年配种、N+1年出生、N+3年二岁出道。幼驹出生时身份与参数固定；零岁、一岁不报名、不生成年度TF。二岁自动进入现役、AI安排首战。现有二岁目标用来规划配种和补充缺额外来马，降低目标不会删除已出生后代。竞赛退役与繁殖引退分别管理，后者保留档案。

自建马支持配种实力、亲本搜索和血统预览；可从世界个体或可引入的核心资料选择。引入资料会先显示具体年龄和亲缘名单。同一来源只实例化一次；已有祖先过老时不能重新变年轻。普通马的精确B、能力和适性不进入公开详情或创作导出；自建马能查看自己填写的值，其自动后代继续隐藏。

## 资料与事实边界

本地库含240匹核心个体：日本、欧洲、美国分别30匹牡马、50匹牝马；加上共享祖先共1,430个唯一来源个体。核心个体的父母均有JBIS公开资料依据。每条保留来源编号、原名、别名、真实性别与出生年、父母链接、证据页及核对状态；部分父母关系依据子代页面中公开的血统表核实。游戏运行不需要联网。

年代配额因资料完整度略作调整。50匹牝马不是50个独立牝系，祖先重复出现时共用身份。三代尚有178处路径位置缺失，这不是178匹确定不同的马；不确定位置显示“未记录”。逐项见 [资料核对及缺失清单](第三阶段血统资料核对.md)。完整结构化资料为 [chairman-pedigrees.json](../js/data/chairman-pedigrees.json)。

配种实力模板35／50／65／80／90为游戏粗略设定，实例化浮动±5后固定。场地、距离与成长倾向仅做近似，缺资料采用中性生成。它们不是JBIS评价，也不代表对现实繁殖成绩的精确还原。跨年代沙盒允许现实未留种的马成为游戏繁殖马，不虚构其现实子代记录。

中文别名优先沿用项目已有译名，英文及日文原名可搜索；日文补充罗马字检索项，中文使用拼音首字母。资料与游戏个体编号分离，模板更新不追溯修改已经进入世界的亲缘与参数。

## 规则落地

- 普通马B＝round(0.70U＋0.20父母B均值＋0.10出生基础能力映射)。缺亲本取50；自建未填B同规则。赛绩、WTR、伤病与增龄不改变B。
- 子代先按原普通生成器生成，再加一次（父母B均值－50）÷10，最终取整并限制62～100。不复制父母基础能力，也不累加旧血统模板奖励。
- 场地及地区、距离、赛道、成长、气性及重场地五组分别30%父、30%母、40%重新生成；成长重新生成合法巅峰期。祖辈通过父母间接影响。
- 无G1或胜场留种硬门槛。地区名额按二岁目标计算，60%公开声望加权、40%随机，指定保留优先。父本80%倾向同区、20%跨区，份额不足时可放宽，但近亲禁配始终有效。
- 正常父母已竞赛退役、至少三岁、非骟马、未繁殖引退。禁止祖先后代配对及双方父母／祖父母有共同个体；未知祖先不会共享占位身份。同母同出生年最多一匹正常幼驹。
- 年初自然引退概率1＋floor(年龄÷10)%；新加入者当次豁免，牡25、牝22岁起强制引退。找不到合法配对时建立明确标记的架空外来始祖。
- 仅直接子代实际游戏奖金计入父母繁殖榜。年末正奖金最高父本获冠军种马，同额并列，包含该年已引退父本；无奖金空缺。隐藏赛果不影响统计。

## 保存与兼容

数据库升级到v4，完整存档v3接受旧v1／v2。新增谱系、繁殖事件和子代年度统计分项保存；幼驹属于具有稳定身份的马匹实体。年末的出生、出道、统计、评级、时间及两个随机状态在同一事务提交。失败不留下半批出生或重复颁奖。手动槽和恢复点继续使用原有独立快照／事务机制。

繁殖随机流独立于比赛随机流。浏览、筛选、配种预览不抽取正式随机结果。回退至启用前恢复点会回到未启用状态，再启用可重复得到同样结果。完整存档保留所有亲缘、出生事件和锁定快照。

马匹CSV继续兼容旧模板，新增配种实力与来源世界字段。精确B只导出自建马。空白更新保留旧值；新增未填B在整批父母与能力解析后计算，包括子代行位于父母之前的文件。跨世界外部父母必须显式映射，界面支持逐行“外部编号=本世界编号”；不按同名或同号猜测。全部关联通过校验后一次提交。

## 自动验证

开发前复核123项常规和2项长期基线；完成后137项常规测试、2项既有长期测试、3项新增繁殖长期测试全部通过。

新增检查覆盖：核心数量／来源／年代／无环、共享身份、防止祖先恢复年轻、普通随机马留种、骟马排除、自然与强制引退、B固定／范围／隐藏、父母双边继承、近亲限制、指定超额、同母替换、N到N+3生命周期、目标下调、直接奖金与并列冠军、查询去重分页、事务失败、年末恢复重放、v3完整导入、CSV往返和跨世界映射。

五个种子123、43127、995173、77、20260920分别完整运行20年：每个世界产生1,500匹正常幼驹，终点有1,950匹比赛／幼驹档案，现役322～333匹，20次冠军种马年度记录。没有同母同年重复，奖金总和一致，繁殖后代继续留种产生下一代。各世界327～339个父本留下后代，其中297～310个来自随机马群，249～265个从未赢过G1；单一父本占全部出生份额最大约1.07%～1.67%。这是本次五组样本，不作为所有世界的保证。

三种子、每档每代200匹、30代分布对照：

| 20 | 77.89～78.18 | 67～89 | 1.22%～1.60% |

| 90 | 84.79～84.86 | 74～96 | 12.88%～13.93% |

另做三种子、每代100匹、30代实际B重新生成试验，早期与末期平均能力差绝对值小于0.5，末代B均值50.04～52.63，纯父系家系仍有2～3支。该试验单独隔离遗传；近亲限制和自动留种在完整20年世界试验中验证。结果表明B有可测影响但分布充分重叠，不会逐代无条件加能力。

复测命令：`npm test`、`npm run test:chairman:long`、`npm run test:breeding:long`、`npm run build:web`。详细运行统计写入本地`.cache/breeding-*-validation.json`，不作为玩家存档。

## 后续边界

三代史实资料仍可继续补齐178处路径位置；粗略模板参数适合沙盒观察，不适合当作现实种马统计。独立家族分享、年代限定、马主经营、主子马会、系列赛、殿堂、议会、负重、造时和Excel多工作表按计划后置。本轮保留原比赛、TF和G1压力公式及旧模式存档键。
