# 阶段11数量与机制对照登记

本轮先区分供给和排赛，不继续单凭某个种子的合格率调选赛权重。

1. 当前正式机制下，日美默认数量及初始／年度补充同时翻倍，先种子123两年对照，再按发现补43127。保留自然退役，关闭基础种马和繁殖。
2. 对每地区同一半月的全部命名赛事做人数配额最大匹配，每匹马最多分配一场。分别计算本土合法可达、再排除明显实际路线风险、再保护锁定／准备报名、再考虑目标时间间隔四层。不能把每场都有5匹候选误当作全赛期能同时填满。
3. 这是当前世界状态下的可行性诊断，不会替换实际报名；未考虑完整赛季后果。最后一层仅检查目标时间，不声称具备全部前哨适性。没有证明最优赛季安排，也不将取消合理目标当作建议。
4. 若发现可复现的资格／地区赛制解释问题，再做独立机制对照。维持5／8匹、举办率95%、分人数组90%的原口径，保留失败结果与原始数据。默认数量及生产规则在证据充分前保持不变。

执行后记录：两种子翻倍数量的日美八个地区年度均通过人数要求，已据此调整日美新建世界默认。最低供给与现有目标约束分别报告；重要赛事对决、长期TF及性能不与人数合格混为一项，联合验收仍未完成。
