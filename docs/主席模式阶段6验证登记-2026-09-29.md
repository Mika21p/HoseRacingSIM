# 阶段6验证登记

先诊断再修改；保持开赛2匹，人数合格5／8匹，按地区每年举办95%、人数合格90%的标准。前三年TF豁免不豁免人数。

1. 基线：日美默认1000／752、年度250／188，种子123、两年；逐场记录缺马时法定资格池、休整运输可达池、已报名其他比赛、公开适性与目标限制，并保留赛事条件。
2. 根据主要瓶颈只作有证据的局部修改，不牺牲已锁定报名、间隔、伤病和远征目的；不读取隐藏能力选赛。
3. 改后先种子123两年探索，再种子43127两年确认；同版本基线补足第二种子用于配对。无达标依据不更改默认人口。
4. 其他地区以英法默认组合、单种子两年作有限抽查，不能代替全部欧洲国家或七地区验收。
5. 保留自然退役，关闭基础种马和繁殖以隔离马源；记录每年开局结构、青年资格、赛事人数、海外出赛、目标参赛、未锁定改签、规则违规与TF尾部。规则耗时与诊断开销分开。
6. 若局部修改无净改善则撤回，不靠增加人口或改阈值结项。最终分别报告实现、通过、失败和未覆盖，不把诊断完成等同总体验收通过。

执行补记：最终以同一种子补查未锁定改签及锁定保留；原对象比较改为赛事ID／届次比较后重新复跑，保留旧输出。公开赛法定池中的未胜马在最终诊断中按出道机制单独排除。完整结果见[阶段6报告](主席模式阶段6诊断优化与验收-2026-09-29.md)。
