# 主席模式第二轮完善方案：评分、赛史与年末体验

日期：2026-09-19。状态：已按用户批准实施并完成本地验收。实施范围、操作说明、测试结果及性能边界见 [第二轮实现与验收](主席模式第二轮实现与验收.md)。本文件保留批准时的方案表述；当前决策状态已同步至开发目标。

依据：[长期开发目标](马会主席模式开发目标.md)、[第一轮实现与验收](主席模式第一轮实现与验收.md)及当前主席模式代码。

## 1. 本轮目标与范围

把已经能够连续运行的世界，完善为便于长期观察和评价的主席工具：

**查看半月汇总 → 比较公开表现 → 集中评分 → 查看年度及历史榜单 → 评选专项奖项 → 回顾马匹与赛事历史。**

本轮重点解决评分操作分散、历史评价不易比较、候选战绩展示不足及筛选不完整的问题。

交付六组内容：评分工作台、年度与历史榜单、马匹与赛事档案、年度颁奖完善、统一查询与显示清理、旧存档兼容与大数据操作优化。

自动繁殖及遗传建议作为第三轮主题；主子马会与马主偏好、完整骑手管理、系列赛、殿堂、议会、负重、造时及Excel多工作表不纳入本轮。父母编号等预留数据继续保留。

## 2. 评分工作台

### 2.1 半月汇总与赛事评分

- “结果与评分”提供明确的“上次结算”入口，按最后完成的半月查询，正确覆盖年末和跨年。
- 同一半月G1优先，其余按格付、比赛名称及稳定编号排序；在分页之前确定完整排序。
- 每场显示马名、名次、着差、骑手、奖金、上一场评级、机器TF和人工赛事分。
- 原有逐马保存继续可用，新增“保存本场评分”，一次提交本场所有变更。
- 未提交输入在离开输入框或短暂停顿后自动保存为草稿，刷新可恢复；草稿不参与正式WTR计算，并清楚显示保存状态。
- 新增“重拟评分”：清除本场人工赛事分及其草稿，保留机器TF、正式赛果和人工年度WTR覆盖。操作前提示具体影响范围。
- 显示“尚无人工评分”“部分人工评分”“全部人工评分”；未人工评分属于正常状态，不要求玩家补齐才能推进。

### 2.2 年度WTR与历史修订

- 当前年度和历史年度共用一种评分编辑器，始终显示马名、年份、机器年度TF、自动建议、人工覆盖和当前有效WTR。
- 榜单与马匹详情均可进入相同年度记录，避免多份评分互相不一致。
- 人工覆盖允许低于建议值；空白、0和其他数值分别处理。支持“恢复自动评价”。
- 明确修订旧赛事分时，仅重算该马对应年份的自动建议；存在人工年度覆盖时保持覆盖。
- 修改上一年度有效WTR时，同步更新该马用于新报名的上年评级参考；已经形成的报名、历史资格、赛果、奖金和已颁奖项不追溯改变。
- 历史机器TF及原评分版本保持封存；浏览、升级及新年度推进不重新计算旧TF。
- 不为没有年度记录的过去年份自动伪造评价；保留第一轮已有的“未出赛但人工设置年度WTR”记录，其TF仍为空。
- 保存人工评分修订记录，注明对象、年份、修改前后值和时间；不记录隐藏能力。评分保存失败时，正式评分与修订记录均不部分生效。

## 3. 新增榜单入口

| 榜单 | 对象与排序口径 | 主要展示 |
| --- | --- | --- |
| 本年WTR榜 | 本年有有效WTR的现役马，WTR从高到低 | WTR、TF、评分来源、本年G1、出赛数、本年奖金 |
| 历史WTR榜 | 已封存且有WTR的“马匹＋年份”，包含退役马 | 记录年份、当年年龄、WTR、TF、当年G1、当年奖金 |
| 本年奖金榜 | 本年出赛或取得奖金的马，包含年内退役马 | 本年奖金、本年胜场／出赛、G1、WTR |
| 生涯奖金榜 | 所有已有出赛记录的马 | 生涯奖金、胜场／出赛、G1、最高已记录年度WTR |

- 默认每榜前十；“查看全部”进入每页50条的完整列表。最低评级通过独立筛选输入，不采用尚未校准的120／128门槛隐藏低分马。
- 先筛选、再对全部符合条件记录排序、最后分页。不是只把当前页排序。
- 相同主排序值显示并列名次，次序以对应口径奖金、稳定编号确定，翻页及刷新不随机变化。
- 历史榜同一马可以有多个年度条目；年龄使用记录年份年龄。
- 支持马名、年份（历史榜）、年龄、性别和地区筛选。每个榜单独立记住筛选和排序，可一键清除。
- 生涯榜的身份筛选使用当前身份；历史榜地区使用年度快照。旧记录缺少历史地区时，只从可验证的旧成绩补全，不能拿当前归属伪装成历史；无法确定则标记“未记录”。
- 各榜单马名均可进入同一马匹详情，年度WTR旁可进入对应年份的编辑器。

## 4. 马匹与赛事档案

### 4.1 马匹详情

- 分为概况、逐场赛绩、年度评价、荣誉四部分，减少长弹窗一次堆叠。
- 年度评价展示WTR、TF、出赛数、胜场、G1和奖金；全部年份可分页浏览。
- 提供WTR／TF年度趋势图及同内容表格。缺失年份留空，不补0、不连接成确定表现。
- 可按年度、格付、地区、草泥地及距离类别查询出赛记录，并进入对应比赛评分。
- 展示全部G1胜场及当时赛事名称，分页读取；年度奖项也提供完整历史浏览。
- 自建参数继续只对自建马展示；普通AI马及未来自动繁殖后代均遵守隐藏信息边界。
- 公开表现总结只使用出赛记录，标注样本数量，不把少量样本结论写成真实适性。

### 4.2 赛事与马场回顾

- 赛事详情分开显示未来赛事定义和历届比赛，历史包含年份、举办条件、参赛数、冠军与取消状态。
- 历史冠军可点击；查看某一届使用该届条件和姓名快照。
- 已停止举办的赛事仍可通过历史页查到，不要求恢复赛事定义。
- 马场增加基本详情，可查看当前所属赛事及在该马场举办的历史G1。
- 赛历提供各地区、草泥地、距离类别的赛事数量概览，以及创办条件下符合显式参赛资格的现役马数量；不得按隐藏适性筛选人数，也不承诺这些马都会报名。
- 造时纪录、经典对决自动判定及AI报名解释留待后续。

## 5. 年末颁奖完善

保留原7项，建议增加最佳短距离马、最佳中距离马、最佳长距离马、最佳草地马、最佳泥地马，共12项。

| 新奖项 | 严格候选资格 |
| --- | --- |
| 最佳短距离马 | 本年胜出短途或英里G1 |
| 最佳中距离马 | 本年胜出中距离或中长距离G1 |
| 最佳长距离马 | 本年胜出中长距离、长距离或超长距离G1 |
| 最佳草地马／最佳泥地马 | 本年胜出对应场地G1 |

- 继续使用当前主席模式六种距离分类，不改距离边界；中长距离同时进入中、长奖候选是有意允许的重叠。
- 严格模式遵守上述资格；宽松模式把对应G1胜利要求改为对应类型的本年出赛要求，年龄／性别资格仍保留。
- 候选按本年WTR降序，再按本年G1、本年奖金和稳定编号排序；无WTR排在有分马后，不读取隐藏能力。
- 候选以可搜索、可分页的列表选择，展示本年WTR／TF、G1胜场名称、战绩、奖金，可进入详情。
- 每奖可选一匹或空缺，同一马可获得多项。骟马继续归牡骟类别。
- 可为获奖马添加简短评语和一场本年代表赛事；代表赛事须为该马实际参加的届次。
- 颁奖草稿自动保存；切换候选范围后保留选择并标记失效项，正式颁奖前要求修正失效选择，不静默换马。
- 本年与去年优先展示，历史可按年份回顾。旧年份仍保留当时的7项奖，不补发新增奖项。
- 本轮不实现自定义奖项规则、世界马王、投票或已颁奖项追溯重评。

## 6. 统一查询与显示清理

- 马匹支持名字、年龄、性别、地区、现役／退役、自建／自动生成筛选。
- 赛历支持名称、日期、地区、草泥地、距离类别／具体距离、格付、年龄条件和性别条件筛选。
- 结果支持以上适用条件、年份、上次结算、举办／取消状态、人工评分状态筛选。
- 同一筛选内多选取“任一”，不同筛选之间取“同时满足”；显示结果数量和当前条件。
- 改变筛选回到第一页；返回列表保留有效页码和滚动位置，分页越界回到最后有效页。所有筛选都可清除。
- 普通列表、马场管理、候选选择及历史列表每批最多50条；统一小屏按钮、长马名、表格横向滚动和常驻回顶行为。
- 历史结果增加“从列表隐藏”和“显示隐藏记录”；批量隐藏取消届次可预览范围并恢复。
- 隐藏仅改变结果列表可见性。详情直达、马匹赛绩、评级、奖金、荣誉及以后繁殖统计继续使用原始成绩事实；隐藏不会宣称释放存档空间。
- 不在本轮加入真正删除历史事实或批量删除整个世界。

## 7. 存档与性能

- 继续独立IndexedDB，扩展榜单、年度档案、评分草稿、修订记录及显示偏好的存储与索引。
- 同一评分操作的赛事分、年度建议、上年参考、草稿状态、查询摘要及修订记录一次提交；失败保持原正式状态。
- 排名和统计摘要必须可以由正式记录重建，不能作为另一套不可核对的成绩事实。
- 第一轮数据库、完整JSON、10个手动槽和已有恢复点均须能读取；迁移只补字段、索引和可验证摘要，不重新模拟或重抽随机数。
- 旧恢复点恢复后重建新增摘要；评分草稿与修订记录按明确的恢复时间边界处理，不能把回退之后的数据重新带回。
- 数据格式版本与比赛规则／TF版本分别维护。界面和存储升级不提升模拟版本；12项奖的配置按生效年份留存。
- 新增记录纳入完整导出导入和手动槽。旧格式文件缺少新增字段时使用兼容默认值；不静默接受未知未来版本。
- 设置显示最近成功保存时间、世界记录数量；浏览器支持时显示站点存储用量／配额，并标明不是当前单个世界的精确容量。
- 榜单及历史按索引查询，避免打开页面时将全部赛史读入内存。评估退役马按需加载，但不得让加载顺序改变模拟随机分配。
- 大批量CSV预览和完整存档导入导出分阶段报告进度；重计算分批让出界面或移到后台线程。
- 校验阶段可取消；进入最终原子提交后显示“正在保存”，不提供会造成半批数据的强行中断。取消前未提交的预览不改变世界。
- 年末和跨年查询、大量筛选、较深分页均在真实浏览器验证，不只依赖fake-indexeddb测试。

## 8. 引擎与评分校准边界

- 保持第一轮半月制、AI观察选赛、休养间隔、16匹默认上限、TF公式及G1压力参数，避免同时改变体验界面和数值导致问题难以定位。
- 开发验证报告记录出赛间隔、长期未报名比例、各地区取消率、各级赛事满额率、TF分布、G1失常和退赛比例。
- 固定种子验证刷新、打开榜单、改筛选、评分草稿和历史浏览均不消耗比赛随机数。
- 如果数据发现确定的规则实现错误，本轮修复并增加针对性验证；改变TF公式或压力概率另列校准决策，不能静默回算旧世界。
- 开发诊断可使用真实参数，正式页面不得输出这些内部诊断。

## 9. 开发顺序

1. **统一年度查询与兼容迁移**：先建立评分、年份、历史身份快照、索引和摘要的共同读取接口，验证第一轮存档升级。
2. **评分与榜单**：年度编辑、整场保存与重拟、草稿、修订记录、四类榜单及完整分页。
3. **档案与颁奖**：马匹年度趋势、赛事历届回顾、马场详情、12项奖和候选选择。
4. **查询与体验**：组合筛选、状态保留、小屏布局、隐藏／恢复取消和历史结果。
5. **性能与验收**：真实浏览器大数据查询、长操作进度、中断恢复及旧模式回归，更新目标状态与验收说明。

各步骤完成对应测试后进入下一步；存储兼容和历史正确性问题优先于继续增加页面功能。

## 10. 验收标准

### 功能与口径

- 能从上次半月汇总进入一场比赛，一次保存多匹赛事分；刷新后正式分与未提交草稿各自保持。
- 重拟整场评分只清除人工赛事分，机器TF、赛果和年度人工覆盖保持正确。
- 从历史榜修改第1年WTR，在第2年及之后仍准确显示第1年修订；其他年份不被覆盖。修订上一年影响新的评级参考，已经报名的名单不变。
- 同一马不同年份可同时进入历史榜；年龄与地区使用对应历史口径，无分不冒充0分。
- 所有榜单在分页前完成全量条件筛选与排序，改分后排名立即正确，翻页无漏项和重复项。
- 年度评分与奖项超过50条仍可继续浏览；已停止举办的赛事历史仍可访问。
- 12项奖严格／宽松候选准确，评语与代表赛事保存，重复结束年度不重复颁奖；旧年份不补发新奖。
- 隐藏历史结果后各项生涯统计及血统预留关联不变，恢复显示后完整可查。

### 保存与兼容

- 第一轮完整存档、旧手动槽及旧恢复点升级和恢复通过，年初、年末、退役马、无评级马均覆盖。
- 改分事务失败、多页面冲突、刷新及取消长操作不产生半批数据；新增草稿和摘要同样受写入锁保护。
- 新版本完整导出再导入后，评分、排名、奖项、隐藏状态和恢复后的随机行为一致。
- 浏览、排序及改分不重抽已完成比赛；不改变其他游戏模式及其存档键。

### 性能与界面

- 保留现有106项常规及2项长期测试作为开工前复核基线，新增本轮针对性用例。
- 默认世界连续5年；沿用至少1000匹现役、20年历史规模，增加全榜排序、筛选后深分页、历史改分与升级回填测试。
- 每个普通长列表／选择器每批最多50条；完整结果在超过50匹时仍可分页浏览。
- 在记录配置的桌面浏览器及移动视口测试。目标是完成首次迁移后，常用列表与榜单首屏查询渲染不超过1秒；无法满足时记录瓶颈并优化，不将Node测试耗时作为浏览器达标证明。
- 超过1秒的操作显示明确状态；批量校验／导入提供阶段进度和安全取消边界，界面保持可响应。
- 完成生产构建和浏览器操作实测，不自动发布线上。

最终验收场景：玩家继续第一轮的旧世界，完成一场G1的集中评分，修订一个历史年度WTR，比较历史榜，查看某马历年表现及某赛事历届冠军，颁发新增专项奖，导出再导入后继续下一年度。

## 11. 后续衔接

建议第三轮聚焦自动繁殖：配种、出生、到龄出道、亲缘校验、遗传、三代血统和后代观察。届时直接复用本轮年度档案、榜单查询、历史快照与大数据基础，再加入种马／母马统计。

原参考的繁殖概率、资格门槛、四年等待等仍需单独适配。不得因为本轮准备了展示与索引，就宣称血统换代已完成。
