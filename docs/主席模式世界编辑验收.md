# 世界编辑模式首版验收

日期：2026-09-21。已完成本地实现与生产构建，未发布线上。

## 操作入口

1. 进入主席世界，在“管理 → 设置 → 世界规则”开启“世界编辑模式”。第一次开启显示影响说明。
2. 马匹档案选择“真实参数”，查看基础能力、精确配种实力、成长、累计衰退及适性。“世界编辑”菜单进入编辑或修改记录。
3. 基础血统库、导入家系或祖先档案的操作菜单提供单条编辑。窗口明确区分“资料模板”和“世界个体”。
4. 修改后先预览差异，再保存；模板可停用、恢复，或恢复编辑前默认资料。
5. 顶栏“世界编辑中 · 关闭”恢复正常隐藏体验。未保存草稿须处理；关闭不会撤销已保存修改。
6. “编辑记录与撤销”可撤销尚未发生后续游戏数据操作的最近一次修改；否则在备份与恢复中选择“世界编辑前”恢复点。

## 生效范围

- 开关按世界保存，旧档与新世界默认关闭。只读页面不能修改。
- 普通AI马、自建马、幼驹、退役马、繁殖马和纯祖先分别按已有参数与身份处理。纯祖先显示“无模拟参数”，不生成虚构能力。
- 普通马被编辑后仍保留原来源，另记“经世界编辑”；关闭模式后恢复隐藏，也不会获得自建马CSV导出资格。
- 编辑能力、适性、成长和配种实力只影响后续模拟，不重算赛绩、TF、WTR、奖金或已出生子代；修改成长不会清除累计衰退。
- 身份修改不移动所在地，也不改变本年固定的地方奖登记。已出赛或已有子代的个体不能改年龄；幼驹不能借改年龄提前出道。
- 父母使用稳定编号。校验性别、年代、循环、同母年度约束及已安排配种。性别、年龄、地区与已锁定报名／远征准备冲突时拒绝保存。
- 修正亲缘后，实时血统和当前直接子代统计采用新关系。出生事件保存原始父母与遗传快照，封存的荣誉与年度统计不重算。
- 名称、气性及距离相关衍生字段同步更新，历史赛事快照中的旧名称保留。

## 资料库与存档

- 原始内置资料文件不变。世界级覆盖保存基线、来源版本及玩家修改；本世界检索、引入、自动选材、父母查询与家系导出使用有效模板。
- 已实例化种马不受模板编辑影响。配种基准1～100、参考距离、草泥地及成长预设用于以后引入；未设精确基准的导入家系仍使用公开档位或原默认流程。
- 停用的模板不参与新主体引入或自动选材，仍可作为祖先查阅。共享祖先可以跨内置与导入家系复用。
- 修改史实资料标记“玩家修改”，原始来源保留供对照。来源更新不会静默清除玩家覆盖，恢复默认使用保存的基线。
- 数据库v8，完整存档v7，兼容v1～v6。升级初始化关闭开关与空覆盖，不重抽属性或随机状态。
- 对象、修订、关联摘要、恢复点与世界版本通过同一事务提交；过期预览和失去写入权的提交被拒绝。
- 独立保留最近5个编辑恢复点，不占半月与年末额度。UI偏好、翻页和开关不妨碍撤销；推进、编辑历史评分等游戏操作会使旧撤销失效。
- 完整备份保存覆盖、修改记录和撤销状态；公开家系包仍按白名单导出，不携带精确实力，即使当前开启编辑模式。

新增编辑行为覆盖：

- 默认关闭、开关投影、普通马来源保留、随机流不变、过期预览与无实际修改。
- 既往成绩、衰退及锁定报名保护；共享祖先改名、性别与循环拒绝、纯档案不生成参数。

- 撤销与UI偏好、刷新、手动备份兼容；历史记录写入也会阻止旧撤销。
- 编辑事务中断、五个恢复点保留、旧档初始化、完整存档往返。
- 修正已出生子代父母后，原始出生记录与当前亲缘均可保存恢复。
- 内置模板引用导入祖先时复用身份；未来毛色、距离和场地预设生效。
- 无覆盖且关闭模式时，固定种子比赛结果与未加载编辑模块一致。
- UI草稿关闭／返回、预览保存、种马库编辑与关闭后的DOM清理。

长期回归：主席、繁殖、荣誉、系列相关8项全部通过。包含5组20年繁殖／荣誉世界、30代繁殖分布、5组10年系列对照，以及1000现役马／20年历史的存储恢复。记录见 `artifacts/editor-long.txt`。总耗时约826秒。

## 浏览器与性能

使用本地生产构建，在Chrome实际执行点击、表单填写、保存和刷新；不连接或修改玩家现有存档。

| 场景 | 结果 |
|---|---|
| 1440×900桌面 | 普通AI马能力80→92，保留AI来源；真实参数、差异预览及保存可用 |
| 既有种马与模板隔离 | 现存种马配种实力仍为67；模板基准改为100后，新引入为99 |
| 390×844手机 | 无页面横向溢出；关闭及底部预览按钮均在视口内 |
| 关闭与刷新 | 真实参数、私有输入和详情缓存清除；刷新后仍关闭 |
| 1万条模板 | 单条编辑约0.1秒，筛选搜索约0.05秒；列表最多50条 |
| 浏览器运行错误 | 0 |

性能为本机固定数据集测量，不代表所有设备；精确结果保存在 `artifacts/editor-browser.json`。复现脚本：`scripts/check-chairman-editor-browser.js`。
