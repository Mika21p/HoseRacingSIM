# 殿堂投票优化与验收

实施日期：2026-09-21。仅用于中央殿堂；中央、地方年度奖项继续使用原有抽选机制。本次不发布线上。

## 规则

保留所有具备资格的候选。五项公开生涯指标按固定尺度换算：G1 为 `100n/(n+4)`，评价为 `clamp(2.5×(评价−100),0,100)`，荣誉为 `100n/(n+4)`，奖金为 `100n/(n+6000)`（万），胜率为 `100×胜场/(出赛数+5)`（不足5次为0）。缺失指标为0；评价仍采用已核准WTR优先、否则TF−5；系列荣誉继续按原规则去重。

五项成绩倾向归一化为综合成绩分P。五项全为0时，采用G1 40%、评价30%、荣誉20%、奖金5%、胜率5%。新建中央理事默认使用该配置，随机和弃权均为0；旧理事配置与地方新建默认值不改变。

距离与场地爱好按照公开成绩分布加权，两组平均值之和除以20，总影响为−10～+10。非本地区扣除地方倾向百分数，不在去年支持名单中扣除延续倾向百分数。最终确定性分数为 `S=P+爱好−地方扣分−延续扣分`。地方或延续为100%时，另行严格限制支持范围，避免正爱好抵消扣分后支持圈外马。混合倾向没有有效去年对象时忽略延续项；纯延续则弃权。

支持须同时满足：原有参选资格、G1/评价/荣誉最高标准分≥60、P>0、S>0、S≥可认可候选最高S的85%。特批提名不越过认可标准，主席直接特批入选仍可使用。

在认可范围内，每位理事按S加入最多±3×随机比例的扰动后择优选择前三匹。随机为0时无扰动；同分先比较G1/评价/荣誉最高标准分，再用世界种子、年份、马匹身份派生的共享平票顺序。同配置、同去年记录、随机与弃权均为0时选票一致。名额不足留空；按配置概率逐名额弃权，不递补。

每匹完整计票、包含弃权的总票权分母、默认60%门槛均不变。高度相似的优秀马、较高随机与相互冲突的地方/延续偏好仍可产生合理分票，不保证每年有人入选。

## 实现与兼容

- 殿堂轮次使用版本2，冻结参数、公开指标、理事配置、去年有效支持、年度平票种子及本轮随机种子。
- 殿堂随机状态独立于年度奖、比赛、AI与繁殖；候选扰动由成员和候选派生，加入普通候选不改变其他马的扰动。
- 按配置和去年支持名单缓存计算，缓存上限限制内存；预计算候选随机种子，只保留排序前三名，避免大量临时对象。每100位理事报告进度并允许取消。
- 逐票记录公开分数、爱好、地方/延续扣分、随机调整、最终排序分及弃权原因。历史校验可以从冻结轮次重放，并核对类型分票和总票。
- 导出版本8，接受版本1～7旧档；数据库表结构不变。旧版轮次按旧方式显示、校验，旧殿堂身份不重算。已有本年投票必须主动新建轮次才应用新算法。
- 界面明确显示资格、最低认可标准、支持状态、新旧投票规则，以及逐理事的评分与弃权说明。

## 性能

采用同一运行环境、相同当前世界数据，仅替换投票模块。旧版参照提交：`9152154365c60dfefc0f1b303b4c8453d7b9b2a8`。每种负载交替运行新旧版各3次，比较中位数；计时包含投票计算，不包含世界克隆和存储。10,000匹马全部达到成绩底线，包含随机和弃权，属于大量优秀候选同时存在的压力场景。

| 历史马 / 理事 / 类型 | 旧版中位耗时 | 新版中位耗时 | 新/旧 |
| --- | ---: | ---: | ---: |
| 10,000 / 1000 / 1 | 5346毫秒 | 2334毫秒 | 0.44 |
| 10,000 / 1000 / 1000 | 10845毫秒 | 11572毫秒 | 1.07 |

两种负载都通过“不超过旧版两倍耗时”的标准，并验证了100人进度节点和取消后原世界不变。绝对耗时为本机观测值。
