# 剧情模式第四批两季体验细节清单

日期：2026-10-28；分支：`feat/story-mode`。本轮仅只读梳理和建议，未实施以下项目。

依据：[总体优化方案](剧情模式1998-1999界面与结构优化方案-2026-10-28.md)、[第三批职责整理](剧情模式第三批控制器与样式职责整理-2026-10-28.md)。前三批已建立四区导航、资料筛选和独立控制器；第四批不再重复大规模布局改造。

## 2. 代码依据与重要口径

### 2.1 结束后开放不等于已经发生

- `js/rules/era-world.js`的`yearbook`使用`run.ended || run.settled.includes(e.id)`开放赛事。提前结束时全开放是现行规则，不是此轮要修的bug。
- `js/ui/era-render.js`的`renderYearbookBody`用`yearbook.length`配“已发生”，`organizeRecords`又把同一区域scope叫“全部已发生”。D4-01应同时修标题、筛选标签及条目标识，避免只改一句。
- actual为null时只展示史实；不能写“玩家未参赛，按史实推进”，因为提前结束后该赛事可能根本没有被本局结算。百科当前仅actual存在时显示本局对照，应保持。
- settled与worldResults按既有数据读取，不据显示需求回写或补齐。若数量不一致，应展示可确认口径，不能自动修档。

### 2.2 跨年纪事先解释，不改时间轴

- `js/data/era/storylets/1998.js`的`year-end-transition`使用1998年度总结，触发窗到1999-01-31。
- `js/rules/era-storylets.js`待播及纪事快照保留id/textId/raceId/date/content等；无关联赛事的回顾可能使用当时run.date。`summaryYear`并未直接作为独立字段保存在该快照上。
- UI不应为了归到1998分组去改date，也不应只看run.date或所有textId年份就给每段剧情定义“所属赛季”。最小方案仅对明确年终片段增加说明，未知旧快照维持原日期与正文。
- 现有年份/月度筛选代表快照日期；若未来增加“回顾年度”独立维度，应另行设计，不偷偷改变当前筛选含义。

### 2.3 资料互链只用可靠ID

|来源|当前关联依据|本批可行范围|
|---|---|---|
|百科|entry.id、raceId、horseId、year|赛果互链、跨年同马条目|
|纪事/当前待播片段|快照raceId（可能为空）|有raceId且目标已开放才链接|
|年鉴|edition.id、results horseId|同raceId百科；同马多条时列选择，不自动挑某篇|
|新闻快照|id、eventSequence、tokensSnapshot等，无独立raceId|本批暂不做新闻→赛果自动互链|

新闻`eventSequence`来自生成时事件数，不是统一承诺的直接raceId；不能简单拿它当事件外键，或依靠RACE_NAME/标题找相似比赛。要补这条链需要另行明确关联合同，不夹带进纯UI收尾。

## 3. 推荐实施包

### A包：结束与空态口径（优先）

D4-01、02、03、08。影响集中在现有渲染标签、空态及结束页查阅入口，最少涉及规则推导，不需要新数据字段。完成后提前结束和正常结束都有清晰的“结束但可回看”体验。

### B包：可靠资料定位

D4-04、05。需要在控制器增加临时来源/目标导航状态：先检查目标存在、已开放，再更新面板和相关筛选；展开目标后用preventScroll聚焦并定点滚动。返回时恢复来源面板、筛选及位置；不把整份run复制进导航历史，不无限堆积历史栈。目标不可用时保留来源并提示，不能留下空白页。

### C包：跨年辅助说明

D4-06、07。保留体育小说正文，在正文外添加准确、克制的年份/年度回顾说明；不继续加一层常驻说明占据主区。年度归属不确定时不贴错误标签。

不建议一次同时实施A/B/C：先处理口径，再接导航，最后看是否仍需要额外说明。此顺序是建议，不代表三包已获实施授权。

## 4. 最小验证要求（未来实施时）

- 提前结束于1998、跨年后提前结束、正常1999结束：开放查阅总数与已结算数分别正确，未发生赛事无本局结果。
- 未出赛、未读为0、尚无新闻/纪事、筛选零命中各有对应空态；重置恢复默认且不保存/推进。
- 待播1998年度回顾＋run.date在1999：正文、令牌、快照日期不变，辅助说明不误导。
- 互链目标存在/缺失/未来未开放、同马跨年多条、当前筛选隐藏目标；返回来源恢复筛选与焦点，导航前后run与存档不变。
- 审核标签仍分别遵守1998草稿、1999定稿、旧快照自身状态，不顺带追认。
- UI专项、常规`npm test`、构建；真实应用隔离存储定向核查本包交互与适用布局。不能把此清单当成已执行验收，也不重启用户已终止的全季/宽屏验收。
