## 2. 评分与历史口径

- 草稿只保存输入，不参与年度建议计算；可刷新恢复，也可以整场正式提交。
- 单场人工分优先于该场机器TF；年度自动建议取本年最高有效赛事评级。
- 人工年度WTR可以低于自动建议，后续比赛只更新建议。“恢复自动评价”清除人工覆盖。0分与空白不同。
- 修改旧赛事分只更新该马对应年份的建议；已封存机器TF不重算。历史年度人工覆盖同样有效。
- 修订上一年WTR会更新新报名可用的上年评级参考，已经形成的报名、资格、赛果和奖金不追溯改变。
- 修订记录与正式评分同一事务保存，失败不留下半条修改。重拟评分保留年度人工覆盖。
- 历史榜按“马匹＋年份”展示当年年龄、地区与评价；缺失旧地区只能从实际成绩补全，无法核实时显示“未记录”。
- 生涯奖金榜的最低WTR筛选使用本年及历史最高已记录年度WTR，退役与新年未评分不会错误排除马匹。
- 普通AI马不渲染真实能力、精确适性或巅峰参数。公开摘要标注样本数，不能等同真实适性。自建马仍可查看自建参数。

## 3. 模块与兼容

继续使用原生JavaScript及 `window.Keiba`。增加以下独立模块：

| 文件 | 职责 |
| --- | --- |
| `js/rules/chairman-office.js` | 公开筛选、并列排名、年度改分、整场评分与修订 |
| `js/chairman-history.js` | 历史分页查询、索引读取、历史回填、评分持久化准备 |
| `js/chairman-office-ui.js` | 工作台、榜单、档案、颁奖、筛选及草稿交互 |
| `js/chairman-worker.js` | 后台CSV预览、JSON解析校验与文件序列化 |

原独立数据库名称不变，结构升至v3。新增草稿与修订存储，补充历史WTR、赛事显示顺序、马场及赛事索引。大型历史查询以256条为一批读取，每页最多展示50条，避免逐条浏览器事件及整段历史渲染。

完整存档格式升至v2，仍可导入首轮v1文件。旧手动槽和旧恢复点保留原有作用，导入使用世界副本，不覆盖原世界。旧资料缺少摘要时从真实成绩回填；已完成第二轮回填的世界不会在每次恢复时重新扫描全部赛史。旧游戏模式的存档键未变。

CSV校验、完整存档解析及序列化在Worker内执行。停止校验会放弃未提交结果；进入数据库保存阶段后按完整事务边界停止，不保存半批。取消提示和进度在当前弹窗中可见。点击停止早于Worker创建的情况也能取消。

## 5. 真实浏览器验证

环境：Windows，Chrome 153，16个逻辑处理器。另检查390像素移动视口，页面无横向溢出，测试后恢复正常视口。

实际界面完成：继续旧世界、历史WTR设0及恢复自动、整场多马评分草稿刷新恢复、正式保存与重拟、马匹年度趋势、赛事／马场历史、第二年专项奖选择与评语及代表赛事保存、封存进入第三年、CSV预览后导入并搜索核对、1万行CSV校验即时取消、完整存档后台文件生成。

浏览器性能测试使用 [独立测试页](../tests/browser-chairman-office.html)，构造1000匹现役、20年、3240届比赛、51840条逐马成绩和20000条年度评级。使用临时数据库，结束后自动清理，不读写实际游戏存档。

| --- | ---: |
| 首次写入整套大型测试数据 | 28.43秒 |
| 历史WTR榜首屏查询 | 791.5毫秒 |
| 组合筛选后深分页 | 547.4毫秒 |

表格插入耗时来自测试页，不等同完整应用页面渲染耗时；普通游戏页面另做实际操作和移动布局检查。大型历史榜、筛选和结果查询满足本机首屏查询1秒内目标；首次整库写入仍较慢，不能宣称任何规模、任何设备均秒开。

测试期间发现完整恢复反复扫描全部历史，已改为只在旧资料需要回填时执行；同规模“推进＋恢复”从约15秒降至约0.37秒。导出／导入仍需要构造完整文件，内存占用随完整存档规模增长，本轮未实现流式文件格式。

## 6. 模拟观察与下一轮边界

[固定种子观察结果](主席模式第二轮模拟观察.json)由 `node scripts/audit-chairman-world.js` 生成，种子995173，默认世界连续5年，共9649次出赛。

- 出赛间隔最少3个半月，平均约3.97个半月；该样本没有出现可出赛但连续6个半月仍无报名的观察点。
- 日本、欧洲、美国各270场，取消分别3、9、6场。
- G1参赛653次，压力触发50次，约7.66%；全体退赛290次。
- 90场G1中11场满额；720场OP中292场满额。精简赛历下G1密度与高龄／性别条件的影响值得继续观察。
- G1完赛TF中位数97、90分位116、最高135；OP对应96、116、147。机器评分目前依据表现值，不能仅凭格付理解为现实评级。

这些是一组固定种子测试的观察，不是对所有存档的统计结论。本轮保持现有TF、AI和压力参数；下一轮如要调整评价尺度或大赛吸引力，应独立讨论并保存规则版本，不能回算旧TF。

自动繁殖、遗传、三代血统、后代观察仍未实现。系列赛、殿堂、议会、负重、造时、主子马会管理与Excel多工作表也不属于本轮交付。后续可在本轮赛史和年度查询基础上扩展。
