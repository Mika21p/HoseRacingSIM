## 已实装的机制

常规、传奇的生成分布保持原规则。主席模式使用独立配种分支，共享亲缘、祖先因子和适性组合规则。

| 项目 | 规则 |
|---|---|
| 个体竞赛能力 | 自身比赛使用，不直接叠加到后代能力 |
| 繁殖素质 Q | 1～100；隐藏；影响子代均值 |
| 遗传稳定度 S | 1～100；隐藏；影响子代波动 |
| 公开声誉 R | 自身和出赛子代实绩；不反向修改 Q、S |
| 架空始祖 Q / S | 50＋2d26－27 / 60＋2d21－22；独立于竞赛能力 |
| 子代竞赛能力 | 81＋0.18×(父母平均Q－50)＋(2d20－21)×(1.15－0.006×父母平均S)＋配合奖励；四舍五入，62～100 |
| 突破 | 3%抽90～100，与普通结果取较高值 |
| 配合能力奖励 | 母父相性＋0.6；多样性＋0.4；合格远代强化＋0.4；不套用常规软保底 |
| 子代 Q / S | 50＋0.65×(平均Q－50)＋2d16－17 / 50＋0.60×(平均S－50)＋2d16－17；四舍五入并限1～100 |
| 适性 | ◎○△固定22%；优秀组合基础8%，最高20%；七种合法组合 |
| 近亲 | 禁止直系及较近侧≤二代、另一侧≤三代；3×3仅保留风险，不给远代能力与优秀组合奖励 |

## 自动繁殖与实绩评价

- 年度统一留种；指定保留优先，其余60%公开声誉加权、40%均匀抽取。公马目标为地区产驹目标的40%且有需求时至少四匹，母马为120%。
- 手动配合优先；母马每年一次。自动父马每地区上限为 max(1, floor(目标×20%))；手动可以超额，但计入使用量。
- 本地／外来倾向80%／20%，空池回退；20%均匀探索，80%按公开权重抽取。
- 权重：1＋R÷25；母父相性×1.25；专精或互补×1.15一次；多样性×1.10；出赛子代不足五匹×1.25；近五年当地占比不足5%的已知血系或明确架空家系×1.15；有公开依据的场地路线×1.15；3×3、3×4、4×4风险分别×0.35、0.65、0.85。
- 为提高性能，加权选择使用等价的拒绝抽样；所有候选先通过同一共享亲缘规则。隐藏Q、S不进入权重或留种排序。
- 自身评价为评级、G1、奖金百分位均值；子代评价为70%评级百分位＋30%胜出比例。自身权重10÷(出赛子代数＋10)。无评级的出赛子代按50处理，未出赛单列。
- 五档实绩阈值仍为90／75／60／40；无出赛子代显示“尚待子代验证”。公马5／15匹、母马3／6匹为可信度分界；至少八匹出赛子代才按评级百分位IQR的20／40分界描述表现分散程度。

新增“母父与母系”“年度繁殖报告”入口。母父成绩与直接子代分栏；母链断点标记已知起点，不冒充现实族号。配种页保留横向血统图，显示公开评价、样本量、配合来源和亲缘提示；普通界面不显示Q、S、预测均值或奖励数值。编辑器可查看和修改Q、S。

新出生快照用30个路径槽位＋去重祖先资料保存四代血统、成立配合、风险和规则版本，不嵌套祖先快照。事务内复用冻结快照，个体遗传值和竞赛状态仍独立复制。查看、预览、读档不重抽。完整存档／数据库升级到版本10，新增年度报告存储；旧报告不重算。
