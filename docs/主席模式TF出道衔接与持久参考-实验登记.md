# 出道衔接与持久参考实验登记

沿用日美各 80 匹、每年各 20 匹补充、三种子 123／43127／995173、六年、前三年豁免、无繁殖、自然退役；正式评分及排赛不改动。

每次真实比赛只模拟一次，再平行回放三组评分：旧原型、仅持久参考、持久参考加统一出道结算。保留原有比赛事实哈希，核对与上一轮相同。

## 修正

1. 持久参考：每马保留最近 12 条原始评分，不因半年无出赛清空。参考权重每 12 回合减半，计算衰减最多 120 回合，避免数值下溢；这不是分数随时间直接下降。
2. 条件迁移：同场地权重 1，异场地 0.15；距离差不超过 400 米为 1，401～800 米为 0.4，更远为 0.15。两者相乘，再乘时间权重，选择权重最高五条。有效权重总和控制它在多马共识中的影响。
3. 出道衔接：赛前资格为 0 的马，在任何地区首次有有效完赛、且原型仍无任何评分时，比赛结算末尾补一份明确标记的暂定出道测评。若已经通过该场正常评分取得 TF，不重复补分。退赛不补，开局自带资格的成年马不补。
4. 出道测评只在需要补分的新马子集中，根据本场实际相对着差，以子集最佳表现 85 附近为起点计算；单马时约为 83。它不是 OP 正式单场 TF，不冒充历史赛事，也不把这份赛后资料用于本场重赏评分；只供后续交手借用。当前尚无简化晋级模块，因此这是评分接口实验，不是实现完整一键晋级。
5. 高声望 G1 柔性加成参数不变，仍与原始分分离，不复利传播。

## 验收

- 第 4～6 年，每地区每种子全部完赛及重赏正式单场 TF 覆盖均须达到 90%。出道测评单独统计，不计入正式单场覆盖，避免通过定义调整掩盖缺分。
- 所有赛前资格 0 的有效完赛马，赛后都有原始参考记录；现行晋级获胜者也必须满足。退赛不强行满足。
- 旧原型与上一轮六年逐年统计一致，世界比赛事实哈希一致；各评分组仅回放同一事实，不反馈排赛。
- 检查旧分、异条件分权重确实下降；同条件新成绩在冲突时优先；高声望加成不进入原始历史；统一入口不改变比赛事实。
- 报告整体、重赏、高声望 G1 原始分分布和变化，不能把覆盖提高直接当成评分更准确。

预期风险：当全场只有一个低可信参考时，降低其相对权重仍不足以改变它单独决定尺度的事实；异条件能力差异与长期衰退可能使借分不准确。本轮必须保留暂定身份，后续需要单独验证评分可信度和绝对尺度。
