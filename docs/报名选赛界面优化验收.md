# 报名选赛界面优化验收（2026-09-23）

## 已实现

- 普通、传奇、肉鸽共用紧凑赛事列表，替换长文本下拉框与大卡片。按马龄年月分组，默认展开最近两个有结果的月份，不分页；可展开／收起全部。
- 选择使用赛事ID与参赛时间组成的键，不默认选第一场。同时只有一处详情与确认报名按钮。筛选排除或时间变化使计划失效时清空选择并提示。
- 地区、马场、类型与原有疲劳规避放入更多筛选；草泥、级别、距离直接显示。地区未选时禁用马场且不生成全库选项；地区内的马场支持原名和中文别名搜索，移除地区清除不适用条件。其他条件不会改变马场选项来源。
- 新增共享 RaceSelection：统一 normalize、venue、trackOptions、matches、prepare 及列表渲染。删除 app 与 render 两处重复筛选逻辑。旧日本四场筛选清除，保留其他有效筛选。
- 举办地统一显示国家／地区－马场。报名、详情、赛果、历史及剧情地点文案同步；报名时在 race.venueDisplay 保存展示快照，后续优先读快照。巡回模板明确保留巡回含义，不猜测具体马场。
- 多模式共享报名流程。查看和选择不生成对手、不消耗机会、不推进时间；确认时从最新计划重新校验，再沿用原除外、远征、疲劳及阵容锁定流程。
- 深绿金色风格、窄屏紧凑换行、键盘操作与焦点样式。选择赛事收起筛选菜单，避免遮住详情。更新帮助与资源版本。

## 验证

- 项目快速测试273项通过；最后补充别名接口与资源版本后，13项相关定向测试通过；网页构建通过。
- 新增测试覆盖国家与路线区分、历史展示快照、地区启用马场、中文别名、多地区增删、级别筛选不清空马场、选中失效、60条候选及单一确认入口、预览不抽随机数。
- 浏览器在测试专用4岁G1获胜马存档上展示超过250场真实可报名赛事，完成地区筛选→马场搜索→选择→键盘操作→报名→保存读取→取消报名。
- 同一测试存档分别使用普通、传奇、肉鸽的生产渲染入口，候选数量一致，禁止随机抽取的监测下均正常渲染。
- 1440px桌面、390px窄屏及长英文名称截图检查，无横向溢出，页面脚本错误0。
- 浏览器测试脚本：scripts/check-race-selection-browser.js；报告：artifacts/registration-browser-report.json；截图：artifacts/registration-desktop.png、registration-mobile.png、registration-mobile-long-name.png。

## 边界

本轮不调整资格、数值、远征规则、现实赛程分类、主席办赛或剧情报名机制。选择和月份展开属于当前页面状态；重新读档不恢复未确认的赛事选择。已报名信息随原存档保存。未部署线上。
