# 主席模式连冠系列与内容分享验收

日期：2026-09-21。完成本地实现，未发布线上。

## 使用入口

- **赛历与马场 → 系列赛**：创建、编辑、复制、停办、查看本年分站和历届冠军。选择现有G1／G2／G3；保存前校验资格交集，间隔、路线及重复组合给出提醒。
- **半月汇总**：显示首冠、连冠和全胜奖金。马匹档案显示挑战目标及永久系列称号；殿堂候选和投票依据分别展示中央奖与系列荣誉。
- **赛事／系列的更多菜单**：导出单场、选中比赛、系列及全部赛历；导入入口提供来源处理、地区与马场映射、改名、差异和整批预览。
- **繁殖 → 更多 → 导入血统家族包**：先加入基础血统库“导入家系”。从模板详情选择年龄（默认10岁）、地区及是否指定留种，再确认引入。未启用繁殖时仍可导入及浏览资料，实际引入前需启用繁殖。
- **马匹、基础血统和繁殖档案**：导出主体及递归祖先的家族包。自建马精确参数继续通过原CSV分享，完整游戏继续使用完整存档。

## 实际规则与边界

### 系列届次

同年全部分站由同一匹马取胜才授予全胜奖金和称号。取消、无完赛胜马、失利或年龄不符产生无冠军届次；其他非系列赛事失利不影响挑战。新建系列不追认已举办比赛。

首次成员赛事的名单锁定或远征准备触发本届冻结；到比赛实际结算时也会固定本届。仅到达比赛日期但尚未锁定的本地赛事仍允许编辑。冻结后的成员赛事删除、改日期、改条件及系列停办不改变本届，各站名单仍按正常时间选拔。删除成员比赛会停办关联系列的未来届次，并在界面说明影响。

发放以“年度＋系列编号”为唯一标识。系列奖金计入年度及生涯总奖金并保留系列小计，父母直接子代奖金和冠军种马统计包含该金额；不写为单场比赛奖金，不增加骑手奖金、胜场或G1数。

同年同组分站可有多个系列，各自发奖金；殿堂荣誉取这组称号的最高权重，跨年或不同组合累计。已完成投票不重算。

### AI追逐

扩展现有目标效用及备选流程，使用互斥2／6／10加成与最高3点奖金吸引力。同场多系列只取最高，不累加。赢下此前全部分站的马为下一站保留恢复和行程，仍受正常资格、伤病、休养、容量和满员选拔限制；不读取隐藏能力来决定连冠待遇。

### 内容包与家系

带版本的JSON包以稳定来源识别对象；同名不自动合并。重复来源默认跳过，也可明确更新或新增副本。更新展示差异，预览绑定当前游戏版本，推进或编辑后须重新预览。预览在副本计算，整批成功才提交；后台校验显示进度，提交前可取消。

赛事包自动包含必要地区、参考环境、马场及分站；不含报名、赛果、正式评分或已发荣誉。导入后统一更新报名计划，避免一包内每创建一个系列就重复排赛。

家系包只含名字、别名、性别、毛色、来源、父母、游戏年代、史实出生年及公开配种档位。无精确能力、适性、巅峰期、B、随机状态或可计入本世界的外部赛绩。资料先入库，确认引入才建立繁殖候选，祖先仅为共享档案。已有来源个体不能重复引入或恢复年轻；年代、性别、循环和共享来源冲突均拒绝。更新模板不重算已有马和子代。已公开档位在对应区间重新生成B，其他参数沿用现有生成器，使用独立保存的内容随机流。

### 存档

数据库v7，完整格式v6，兼容v1～v5。旧世界先保存“系列与分享升级前”恢复点，再初始化空集合；不补造历史冠军。定义、年度届次、奖励、家系模板和来源映射分项保存。比赛、奖金、称号、AI及时间同事务提交；失败不发半份奖励。10个手动备份、自动恢复点、完整存档和删除游戏使用共用实体／历史集合覆盖新数据。

## 验证结果

- 常规回归：183项通过（原169项，新增13项系列／分享行为及1项界面行为）。
- 主席长期回归：默认世界5年、1000现役马＋20年历史保存／分页／恢复通过。
- 繁殖长期回归：5组种子各20年、30代遗传与家系存续试验通过。
- 荣誉长期回归：5组种子各20年评议、地方奖与殿堂通过。
- 系列专项：冻结、删除、跨年、漏赛／取消、重叠奖励、荣誉去重、AI追逐及伤病、直接子代奖金、事务失败、升级恢复点、赛事往返、家系隐私、来源冲突、模板更新和引入后配种均覆盖。
- 真实Chrome：1440×900完成创建三站、推进至全胜、领取3000万、导出赛事包、跨世界导入、导入家系并引入10岁繁殖马、刷新恢复；390×844检查系列列表和编辑窗口，无页面横向溢出，关闭和保存可达。
- 一万节点家系在真实浏览器分100批预览、保存、重载及深分页查询，每页50条；性能与最终系列对照统计见下方自动汇总。
- 生产构建通过。测试数据与截图保存在本地artifacts目录，不写入玩家游戏。

最初的长期试验组合包含互斥年龄资格，被校验正确拒绝；已改为同地区、同场地、足够间隔的可行春秋赛历后重新执行。该测试赛历只用于测试，不添加到玩家世界。

## 十年对照与性能汇总

种子17、37、73、131、811，各运行有／无系列两个世界10年，初始90匹、每年补30匹；三站统一可参赛年龄、场地和距离，安排在3／6／10月。两组使用相同初始世界，不把后续不同比赛消耗造成的随机流分化当作同场固定随机对照。

| 指标（5组汇总） | 无系列 | 有系列 |
|---|---:|---:|
| 总出赛数 | 36581 | 36458 |
| 仍可全胜时的后续分站机会 | 65 | 67 |
| 前站连胜马实际参加下一站 | 41 | 59 |
| 自然全胜届次 | 4 | 6 |
| 无冠军届次 | 46 | 44 |
| 分站取消 | 0 | 0 |
| 全年零出赛现役马累计 | 1 | 1 |

连续出赛率由63.1%提高至88.1%；全胜4→6次（各50届）。有系列组所有冠军均获得一次对应奖励，重复发奖为0；仍需正常比赛取胜，不保证完成连冠。

浏览器一万节点：预览578毫秒，分100批；深分页首批50条查询38毫秒，保存／重载／完整存档校验通过。该数字是当前机器实测，不是所有设备的性能保证。
