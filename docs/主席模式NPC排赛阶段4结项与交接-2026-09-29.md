# 主席模式 NPC 排赛阶段 4：结项与交接

日期：2026-09-29

**阶段状态：探索与实验交付已完成，初步验收部分通过，带明确遗留项结项。原定默认人口与正式世界整体验收尚未通过。**

本次结项依据用户在阶段性评审后提出的“完成阶段4”，收束人口筛选、资格供给诊断与后续 TF 原型实验，将正式接入和人口复核交给阶段 5。不会把未通过的人口指标改写为通过，也不再为结项追加大型模拟。

## 交付与判定

| 项目 | 交付及证据 | 结项判定 |
|---|---|---|
| 人口筛选 | A 轮 16 个候选及十类场景基线，共 22 个运行、23 个年度；候选均按预登记淘汰 | 实验完成，人口方案未通过 |
| 双倍人口与资格供给 | 新 5／8 匹标准，七单区及组合、补充干预，共 11 个运行、19 个年度 | 诊断完成，翻倍不是合格默认方案 |
| 资格供给瓶颈 | 识别新马缺少机会、非日本 OP 出道路径、次年三岁资格结构变化 | 后续实施方向明确，简化晋级未实现 |
| 历史冠军分 | 正式评分不再读取或积累赛事历史冠军分，旧记录不回算 | 已实现；当轮 385 项测试及构建通过 |
| 新马 TF 与传递 | 统一出道补参考、持久历史、异条件降权；六年小规模回放覆盖改善 | 原型初步通过，未接入正式评分 |
| 新马波动及完整阵容保护 | 两种子、日美各 80 匹、四年；异常参考定向检查、低分排查及边界修复 | 原型初步通过 |
| 高声望 G1 柔性加成 | 原始分低时补差距的一部分、上限 4，不硬补至 110、不复利 | 原型初步通过，参数待联动复核 |
| 默认人口定稿、存档、浏览器、性能 | 尚无新人口达标证据，原型未联动实际排赛 | 转阶段 5，未验收 |

最后一轮原型第 4 年，两个种子的日美各地区整体及重赏评分覆盖均为 100%；1,358 次未胜马有效完赛和 292 次获胜晋级后均有参考。完整阵容已评分记录中原始 TF <40 为 10/3,711（0.27%），>140 为 0，低分均处于后半名次。上述为评分可用性指标，**不能替代比赛人数合格率**。

结项时核对最后原型源码哈希与最终实验报告一致；两组运行均为 complete，边界检查通过，关键人口与评分原始文件存在。本次收尾只更新文档，不将历史测试记录冒充今日重新运行的整套回归。

## 冻结的口径与当前默认值

- 至少 2 匹仍是开赛标准。
- 非 G1／声望低于 85 的 G1，至少 5 匹才达到参赛人数标准；声望不低于 85 的 G1 至少 8 匹。
- 命名赛事举办率目标 95%，对应人数达标比例目标 90%，均按地区、年份分别判定。
- 前三年豁免只用于 TF 建立过渡期，**不豁免原定首年、次年的赛事举办与人数验收**。
- 默认数量保持下表。保留原值是因为尚未找到经验证的新方案，不表示原值已足够。

| 地区 | 开局现役 | 每年二岁马目标 |
|---|---:|---:|
| 日本 | 1000 | 250 |
| 美国 | 752 | 188 |
| 英国 | 340 | 85 |
| 法国 | 300 | 75 |
| 爱尔兰 | 196 | 49 |
| 德国 | 100 | 25 |
| 意大利 | 100 | 25 |
| 合计 | 2788 | 697 |

原 B～D 年度比例、组合定稿和长期留出矩阵没有通过记录：它们在没有合格输入时未执行。本轮结项不补跑已淘汰候选，也不默认重启原先的大规模矩阵。后续按用户“小规模优先”的要求先验证必要问题，只有证据需要时再讨论范围。

## 阶段 5 交接顺序

### 5A：接入出道／简化晋级与 TF

1. 实现各地区一致的简化新马／未胜利机会与结算，以当前实力、成熟速度和概率决定表现／晋级，避免仅提高资格、不提供参考分。
2. 将已验证的持久参考、新马小波动、完整阵容异常参考保护和 G1 柔性补偿接入正式调用链；补充测评与正式赛绩区别保存。
3. 保持资格、伤病、年龄、性别、间隔、运输及锁定规则；不通过改变隐藏能力或强制远征填补比赛。
4. 保存原始 TF、必要修正、种子及结算标记，重载不重抽；不追溯改写旧赛果、奖金、WTR 或荣誉。旧版世界行为和存档策略单独明确。
5. 验证界面、工作线程、导入导出、备份恢复和正常年度结算；正式接入完成前不宣称原型已可在游戏中使用。

### 5B：有限联动复验与人口决定

1. 冻结正式接入版本后，首先对日美既有小规模场景做配对复验，TF 实际参与排赛；区分真实参赛人数与有评分记录覆盖率。
2. 复核第二年三岁马资格供给和新增马等待时间，确认简化晋级确实改善马源。
3. 优先复查已暴露缺口的地区与年份，按 5／8 匹标准记录失败，不靠全球平均掩盖地区问题；仍保留第一、二年的办赛验收。
4. 只有办赛与性能证据支持时才确定分地区新默认值。先不直接翻倍，也不从日美小样本推定七地区均达标。

### 5C：兼容、性能与本地整体交付

运行受影响的回归与构建，检查浏览器推进、保存、恢复和界面；汇总默认人口决定及仍未覆盖的场景。当前全局均分下移作为跟踪项，不单独阻止原型初步验收，但不能宣称绝对尺度已校准。

交接时阶段 5 尚未启动。本文件保留阶段 4 结项时的状态；后续正式接入与有限验收已执行，最新进度见 [阶段 5 报告](主席模式阶段5集成实现与验收-2026-09-29.md)。
