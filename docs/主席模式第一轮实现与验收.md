# 国际主席模式：第一轮实现与验收

更新：2026-09-19。该版本为本地测试版，未发布线上。长期需求及后续范围见 [开发目标](马会主席模式开发目标.md)。

## 试玩入口

打开项目首页，选择 **国际主席模式 → 进入 / 继续主席世界**。选择国际预设或空白世界；已有世界可以继续。

国际预设包含300匹赛马、18场现有G1和每半月6场普通公开赛。点击“下一半月”结算本半月比赛；“快进至下一场G1 / 年末”逐回合保存，遇到G1举办日期或年末停止。快进期间可点击停止，已经完整保存的回合保留。

可按下列顺序试玩：

1. 在“赛历与马场”建立马场，创办或编辑赛事；格付、日期、资格、距离、参赛上限和前五奖金均可调整。
2. 在“马匹”加入自建马，或生成随机二岁马群。AI负责报名、行程与骑手；自建马与普通马共用比赛规则。
3. 推进后进入“结果与评分”，点击赛事查看全部完赛名次和退赛标识，为各马填写赛事分。
4. 点击任意马名查看统一详情，为该马设定人工年度WTR，或恢复自动评价。
5. 12月下半月结算后停在年末。选择七项奖项的获奖马，名单自动保存；允许空缺。
6. 结束年度后，评分与奖项封存，再增龄、退役并补充新马。

“马匹”支持名字查询、现役／退役／地区筛选，以及WTR或生涯赏金排序。普通AI马的真实参数从未渲染到其列表或详情中；只在自建马详情中提供自建参数。

## 评分口径

| 内容 | 规则 |
| --- | --- |
| 机器单场TF | 最终表现分＋10＋同场共享整数浮动−5～5；退赛不生成 |
| 人工赛事分 | 可为空或为0；有人工分时替代该场TF参与年度建议 |
| 自动年度建议 | 本年有效赛事评级的最高值 |
| 本年TF | 本年机器TF最高值，与人工改分分开保存 |
| 人工年度WTR | 独立覆盖，可低于建议值；后续比赛不会覆盖 |
| 恢复自动评价 | 清除人工年度覆盖，使用当前建议 |
| 历史评分 | 年末快照，不随新年度或规则变化重算；明确修改旧赛事分只修改对应年份的建议，人工覆盖继续保留 |

改分不会改变名次、奖金和已经形成的参赛安排。结果页显示当时该马上一场赛事评级。旧赛事补分不会改写已经保存的其他场次快照。

首轮TF是试验性内部表现评分，不能等同真实能力。没有采用参考玩法的4d5赛果公式、负重公式或标准造时公式。

## CSV表格与分享

在马匹页或赛事页打开对应CSV工具，下载模板、导出全部或导出列表中勾选的对象。

- UTF-8，模板与导出文件带BOM；支持标准双引号、逗号和字段内换行。
- 保留“模板版本”列，当前值为1；编号为稳定关联标识。
- 默认“新增副本”；“按编号更新”与“跳过已有”需要使用对应对象编号。
- 更新时空单元格保持原值。`#CLEAR`可清除父母编号、马主、毛色及血统模板编号等可选字段。
- 赛事半月列接受1／2或“上半月”／“下半月”，不接受未经转换的周数。
- 年龄＝世界当前年份−出生年份；架空早期年份的出生年可为负数。
- 巅峰期沿用现有引擎的年龄与季节标签，例如“二岁夏”“五岁冬”，不是参考中的年龄＋月＋周。
- 普通AI马不能通过创作CSV导出或修改真实参数。完整世界存档另包含模拟所需内部数据。
- 马场必须按编号及名称正确对应、唯一同名匹配，或在预览中明确映射。不会自动分配到错误地区。
- 预览指出错误行列。全部通过后才可一次提交；任一错误都会阻止整批导入。
- 导入预览阶段可以关闭窗口取消；确认提交使用一个事务。随机批量生成每50匹保存一次，可在批次边界停止。
- 表格文本中的公式前缀会转义，重新导入时还原；首轮不提供多工作表Excel。

## 存档与恢复

主席世界使用独立IndexedDB数据库 `keiba-chairman-v1`，不读取、迁移或改写生涯／传奇／肉鸽／剧情模式的存档键。

- 普通操作及时保存，半月结算在一次事务中提交时间、马匹状态、届次、逐马成绩与随机状态。
- 写入失败保留上一完整状态；计算使用可恢复种子，重试不会重新抽一套赛果。
- 10个手动槽是独立快照。读取槽或导入完整JSON会建立新世界副本，保留当前世界。
- 最近3个半月恢复点及1个年末恢复点使用逆向变更记录；恢复时回退成绩、奖金、状态、评分和随机状态。
- 同一世界只允许一个写入页面；优先使用浏览器锁，数据库租约与版本检查兜底。第二页面可查看但不能推进。
- 浏览器存储不可用时显示错误，不退回仅保存部分数据的方案。清除站点数据会删除本地数据库，重要世界应定期导出备份。
- 切换到“新建世界”不会删除原世界或手动槽。

数据库格式版本、完整文件版本、世界规则版本与评分版本独立保存。年度记录与赛事快照保留当时条件及版本；编辑赛事定义不改写历史。

## 代码入口与职责

| 文件 | 职责 |
| --- | --- |
| `js/rules/chairman.js` | 世界、生成、AI报名、行程、半月与年末、评分变更、校验 |
| `js/rules/race-simulator.js` | `simulateWorldRace`复用单马阶段计算及全场排序 |
| `js/utils/random.js` | 可保存状态的随机源，作用域注入，不改写全局Math.random |
| `js/rules/maturity.js`、`horse-generator.js` | 显式选项取消新模式60保底，默认保留旧行为 |
| `js/chairman-storage.js` | 实体与历史分表、增量事务、恢复点、独立槽、版本／关联校验及写入锁 |
| `js/chairman-csv.js` | 模板、导出、校验预览、映射与批量变更 |
| `js/chairman-app.js`、`css/chairman.css` | 六个主界面、表单、详情、分页和回顶 |
| `js/app.js`、`index.html` | 首页入口与资源加载，保留旧模式入口 |

主要接口：`ChairmanRules.createWorld`、`planEntries`、`advanceHalfMonth`、`finishYear`、`edit`、`scorePerformance`；`RaceRules.simulateWorldRace`；`ChairmanStorage.Store.commitChanges`；`ChairmanCSV.template/exportRows/preview`。

世界内存保存马匹和赛事定义，历史成绩按索引分页读取。每场条件仅保存在届次快照中，马匹不复制整场结果。存档读取顺序与模拟遍历顺序统一，防止刷新改变随机分配。

正常AI间隔至少3个半月；向前查看6回合。根据地区、草泥地和距离类别的已观察TF估计适合程度，未知采用中性估计。长期闲置时放宽估计要求。选拔按本年可用评级、上年评级回退、生涯奖金及随机顺序处理，落选再尝试备选。已进入远征准备的赛事条件锁定，后续编辑用于后续届次。

## 验收记录

- `npm test`：106项通过，含原有87项及新增19项；包含旧模式固定随机输入的完整结果指纹，与修改前一致。
- `npm run test:chairman:long`：2项通过。
- 默认世界5年：810个年度届次、90个G1届次、9,649次出赛，结束后675匹历史马、323匹现役；无同半月重复参赛，生涯奖金与成绩累计一致。
- 合成规模数据：1,000匹现役、20年3,240个赛事届次及51,840条出赛记录。完成保存、最新50条查询、加载、回退及完整导出校验，导出约13.4 MiB。
- 上述大型数据库测试使用Node测试环境中的fake-indexeddb；查询约23毫秒，首次整档写入约24秒。它不是所有浏览器、手机或设备上的性能保证；常规回合走增量事务。
- 浏览器实测：国际开局、16匹完整结果、赛事分联动、人工年度WTR、自建马、CSV错误与有效导入、刷新恢复、筛选保留、手动槽、G1快进、年末草稿与颁奖、增龄换代、完整JSON导入后继续、第二页面只读。
- 检查桌面与390像素小屏布局；普通马详情没有能力／精确适性／巅峰期字段，自建参数单独显示。
- 生产构建沿用现有构建脚本，主席模块随静态资源输出，不自动发布线上。

后续试玩重点是AI排赛多样性、TF尺度与大马群极端表现的体验校准。繁殖、系列赛、负重、造时、殿堂、议会及百大未纳入本轮。
