# 阶段 3 验收预注册

在阶段 3 实现和全年运行前登记，基准为阶段 2 optimized 报告，seed=123，默认开局人口、默认年度补充、真实繁殖，一年 24 回合及年末结算。

- 联合世界跨交通组参赛次数相对阶段 2 的 4684 次减少至少 20%（不超过 3747 次）。这是总量代理指标，不能单独证明每次远征合理。
- 定向用例：有同档同条件国内赛时，普通低声望海外空场不触发跨洲远征；合适强马仍可选择高声望国际目标；有公开成绩支持的国内路线缺口也允许非顶尖马远征。
- 移动与参赛分别计数，统计出发、跨组出发、抵达、返乡、海外参赛、海外驻留回合及最长观察驻留；无后续目标时下一次规划启动返乡，返乡按交通耗时完成。
- 在途不得参赛、不得瞬移；同组/跨组及自定义交通时间、连续跨组成本、伤病退出、跨年、锁定报名、旧存档、归属变更、备份恢复均有检查。
- 每次事务审计开关结果完全一致；资格、伤病、间隔、容量违规为 0。日本单区作为无海外行为对照。
- 开赛率、G1 缺马和耗时仍报告，但根据用户本轮要求，既有覆盖率与性能问题留到后续联合验收处理，不以改动默认人口掩盖。

本轮不调整默认 NPC 数量；人口试验留在后续阶段。
