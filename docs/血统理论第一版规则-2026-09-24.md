## 玩家的选择

父母提供直接遗传方向，祖先提供有衰减的因子。幼驹父母算第一代，查四代30个槽位。母马本身与父马同权，母父通过独立相性和自身因子参与，不替代母马。

|配合|成立条件|收益与上限|
|---|---|---|
|母父相性|父马父系×母父父系命中配置表|母父的赛道因子每级增加0.3方向权重，单方向最多0.6；主席能力计算+0.6|
|祖先强化|两侧四代共同祖先，且祖先拥有已赋值因子|该祖先衰减后贡献额外增加50%；每方向强化最多0.5；主席能力计算+0.4|
|专精配合|父母各有唯一◎且方向相同；双方第二或第三代都有该方向因子|18%机会把现有最高适性移至目标方向；只是交换位置，不增加总量|
|互补配合|父母各有唯一◎且方向不同；双方第二或第三代都有各自方向因子|12%机会将两项目标中较弱的△提升为○；每胎最多一级|
|血统多样性|第三代8个槽位全部有血系，至少6种不同血系|权重向均衡靠拢15%；主席能力计算+0.4|
|祖先特征传递|四代内有明确因子|父母至第四代贡献为1、1/2、1/4、1/8，乘因子级别；按身份去重，基础贡献每方向上限2|

专精与互补互斥，不连续升级，不产生三◎。18%/12%是尝试概率，已经达到目标时不再改变，实际改善率通常更低。祖先基础与强化合计每方向最多2.5。共同祖先没有因子时只提示亲缘，不凭空提供祖先强化收益。

方向权重 = 1 + 父母等级分之和（◎2、○1、△0、未知1）+ 因子贡献 + 母父相性贡献。权重用于分配适性，**不是最终概率**。

## 模式区别

- 常规基础能力仍为2d20+60，所有父母、因子、配合理论均不改变它。先按原有七种适性组合抽取，再按家族方向分配，最后执行一次专精或互补。因此互补能轻微改善组合，血统素质不能抬高速度均值。
- 主席保留逐项40%父、40%母、20%新值的直接适性遗传，再约束为合法组合并执行一次专精或互补。基础能力仍由父母平均素质、稳定度、有限理论奖励及3%突破机会共同决定。所有理论能力奖励合计上限1.5，当前三项全部成立实际1.4；不是速度上限加成。
- 子代素质按 `50 + 0.65×(父母均值−50) + 2d16−17` 生成，稳定度使用0.6回归，限制1–100，防止代际无限累加。
- 母父及其他祖先不再额外叠加一份基础速度；其素质应通过父母世代传递。两模式均继承父系标识、母系家族，保存出生系谱及成立理论。

## 其他遗传与风险

草泥逐项40%父、40%母、20%新值；距离整体、成长、气性、重场分别30%父、30%母、40%新值。草泥、沉稳、重场因子按贡献×5%触发，含强化最多12.5%；后代每方向因子概率为贡献×20%，上限50%，随机保留最多两项且初版均为1级。

直系及共同祖先最近两侧不超过2代/3代禁止配种；3×3、3×4、4×4分别增加15%/10%/5%暴躁覆盖机会，按最高风险一次执行，不扣基础速度。不完整系谱始终提示资料不足，不能将未知当成安全。远代祖先不会因在多条路径出现而按槽位重复堆叠。

## 试验数据与复现

12匹父母涵盖日本瞬发、欧洲持久、欧美消耗、泥地与跨草泥路线，另14匹关键祖先仅赋血系与因子。26匹均使用现有库编号；其余只沿已知父链追溯到已设置血系的祖先，不凭国家生成标签。相性表是4组游戏试验配置，未宣称现实统计上的黄金配合。

身份与系谱取自原有JBIS库；核心12匹的公开资料另行抽查。[大震撼](https://www.jbis.or.jp/horse/0000742976/)、[夏威夷王](https://www.jbis.or.jp/horse/0000729458/)、[伽利略](https://www.jbis.or.jp/horse/0000714343/)等资料用于核对父母与赛绩；[Darley的Dubawi资料](https://www.darleyeurope.com/stallions/our-stallions/dubawi)和[Gainesway的Tapit资料](https://gainesway.com/stallions/tapit/)提供种马背景。这些来源不提供本项目的三类型遗传评分；数值为待评审的设计映射。

- `npm run test:bloodline`：亲缘、资料边界、同种子公平、理论因果对照、适性组合约束、UI与不修改源库。
- `npm run audit:bloodline:pilot`：6组合法配合×2模式，各5000匹，并分别关闭每个成立的主要理论，总计170000匹。生成JSON结果与中文赋值表。
- `npm run preview:bloodline`：本地验证台，端口9194。
- 内部诊断：`createPair(library, fatherId, motherId, mode, { disabledTheories: ['nick'] })`。用于单项关闭对照，不作为正式玩家开关；关闭收益不关闭亲缘风险。

完整试赋值及初测数据见[初测报告](血统理论第一版试赋值与初测-2026-09-24.md)。第一版重点验证方向有效、收益有界与两模式区别；主席世界长期多代选择、育种AI和经济尚未验收。

## 本轮验收与观察

57项检查通过，包含12项血统测试、生产打包、语法、既有主席繁殖与适性规则。独立Chrome页面验证了父母选择、生成、两模式批量比较、理论高亮、近亲拦截及无存档写入；1360像素桌面与390像素手机宽度均检查，无页面横向溢出。

常规六组配合均值均为80.992；互补使大震撼×气槽的瞬发/持久均至少○比例由57.36%升到62.50%；专精使夏威夷王×西沙里奥的瞬发◎比例由30.68%升到34.14%。祖先强化使杜拜威×都市海洋的消耗因子传递率由39.10%升到41.32%，其4×3亲缘风险保持不变。

主席的父母直接遗传已经很强，相同夏威夷王×西沙里奥组合开启专精后瞬发◎仅由86.24%升到86.46%。母父、远祖对当代适性的额外收益也较轻，下一轮应结合体验评审是否提高其参与感；当前保持小幅收益，尚未把这些初测数据解释为最终平衡结论。
