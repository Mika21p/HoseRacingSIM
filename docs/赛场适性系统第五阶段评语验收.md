# 第五阶段：练马师评语接入与界面验收

日期：2026-09-22。状态：已完成本阶段实现及自然语言评语优化，尚未部署。

## 已实现的规则

- 出道前六项评估：实力、草泥适性、赛场类型、距离、成长、气性。新增项读取 `surfaceGrades` 和 `trackAptitudes`，不再读取地区适性。
- 保留五个内部判断层次、原概率与专长权重：`precise`、`close` 属于准确判断；另外保留 `fuzzy`、`unknown`、`wrong`。肉鸽权威复核仍提升一级；剧情仍固定 `close`。
- 新适性评语分别按草泥组、类型组抽取层次。类型完全准确判断三项、基本准确判断两项、模糊判断一项；草泥完全准确判断两个表面、基本准确优先点出一个合适表面（均不合适则指出其中一个）、模糊随机判断一个。未知不生成结论。误判与模糊共用文案，只给一个目标的错误结论，跨过合适／不合适边界。
- 草泥出道限制只使用完全准确／基本准确层次所推荐的合适表面；模糊与误判都不锁定草泥。不增加赛场类型报名限制。草泥 A/B 都表达为合适、C/G 都表达为不合适；类型 ◎/○/△ 分别表达为擅长／合适／不擅长。
- 赛后保留原胜退简评、实力与发挥分析，保留普通 `clear/broad/empty = 50/30/20`、传奇 `70/20/10`。模糊不合不指出目标。
- 草泥 C/G 与负修正触发草泥不合；本场类型 △ 与负修正触发类型不合。○Ⅱ 的 −1 不触发类型不合。G 数值仍为 −20，全部能力修正与分布权重未改。
- 原因顺序：距离 → 草泥 → 赛场类型 → 重场 → 未成熟／衰退 → 实力／发挥。多个因素并存时附加非单一归因说明；摘要不足使用中性评语。
- 新适性诊断读取本场冻结的 `playerCalc.trackAptitude`，不查询后来修改的赛程或当前马匹适性。评语在生涯入账时生成一次并保存；显示和重建认知不重掷。

## 数据与接口

- 保留 `CommentRules.generateDebutCommentDetails`、`accuracyById`、`buildDebutLock` 等现有入口。评语 ID 新增 `track`，既有 `surface` 改为草泥。
- 新适性 `claim.assessments` 每项包含 `target` 与 `judgment`（`strong/suitable/unsuitable`）；草泥不使用 strong，未知没有 claim。只保存说出的定性结论，不保存或显示草泥精确档位。未提及维度保持未知。
- 新评语用草泥是否跑得自在、晚段决胜、提前持续提速、前段持续受压等描述替代档位和范围；不创造独立的爆发力或耐力数值。赛后类型不合也使用比赛展开措辞，归因规则不变。
- 准确赛后不合评语附带 `target: { section, item, label }`。只有被点明的草泥或类型目标得到确认，不向模糊分析附带具体目标。
- 认知版本 `HINT_VERSION = 4`；栏目为 `distance`、`growth`、`surface.grass/dirt`、`track.burst/sustained/attrition`。不再使用地区键或中文地区推断。
- 出道前所有新认知均为 `suspected`；准确赛后不合为 `certain`，能纠正先前错误意见。较弱意见不能覆盖已确认结论。重建从初评和已保存赛后评语顺序重放。
- 获胜、无分析、一般性“未发现问题”不确认新草泥／类型档位。原有距离与成长反馈保留。这仍是基础认知系统，不是完整适性发现或遗传系统。

## 界面与文件

- `js/rules/comments.js`、`post-race-comments.js`、`adaptation-hints.js`：生成、归因、认知闭环。
- `js/rules/era.js`、`debut-lock.js`：六项剧情评估及通用草泥出道约束；肉鸽原有按评语 ID 遍历的复核逻辑自然覆盖新增项。
- `js/ui/render.js`、`js/ui/era-render.js`、`js/app.js`：共用 `UI.trainerCommentCards`，覆盖普通／传奇、肉鸽初评与复核、剧情；赛后结果与历史评语继续使用保存文本。
- `css/game-theme.css`：深绿金色卡片、清晰标签、长文本换行、双列与窄容器单列、键盘焦点。剧情侧栏和肉鸽窄候选卡使用容器宽度决定列数。
- 玩家不显示内部真假标签；剧情移除“五项评估”及逐项准确度。认知来源显示“练马师判断／赛后确认”，未知不等于不适应。
- `js/data/help.js` 与 `index.html`：新规则说明、移除过渡文案、更新相关资源版本。

## 阶段边界与下一步

本阶段不增加主席模式独立评语入口，不实现旧地区存档迁移、完整未知适性发现、血统推断或新数值平衡。已保存评语和历史记录不自动重掷或改写；新开档与新鉴定使用本轮自然语言评语。认知重放仍能读取上一轮的 grades/tendency 结论，但新生成结论统一使用 judgment。

下一步为第六阶段整体验证与发布准备：跨模式完整生涯、编辑与导入导出、后代字段、保存边界、公开／隐藏信息及上线说明。第五阶段通过不等于已完成整体验证，也不代表已经部署。
