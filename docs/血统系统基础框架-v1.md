## 产品原则

- 常规模式：玩家选择喜欢的具名父母、查看祖先和配合特点。所有合法组合共享基础能力分布；懂配种主要提高目标适性与用途的可预期性。
- 主席模式：真实繁殖素质影响后代分布，同样的理论和遗传方向使用不同能力规则。竞赛能力、繁殖素质和公众评价分离。
- 共享个体身份、亲缘、血系和配合判定；不以地区或马名猜测遗传特点。系谱事实与游戏参数分开维护。
- 拟参考的WP理论只提取血系相性、共同祖先、血统多样性、祖先特征。这里的判定和参数是本项目规则，不是现实遗传模型，也不是WP公式复刻。

## 数据约定

个体身份沿用 `id/name/displayName/gender/fatherId/motherId`。实际马匹已有表面、类型、距离、成长等字段时，框架可读取为父母的表现特点。新赋值统一写入 `genetics`，显式遗传字段优先。

```js
{
  id: 'stable-unique-id', name: '虚构示例', gender: '牡马',
  fatherId: 'father-id', motherId: 'mother-id',
  genetics: {
    lineId: 'paternal-line-id', familyId: 'maternal-family-id',
    quality: 80, stability: 50,
    surfaceGrades: { grass: 'A', dirt: 'C' },
    trackAptitudes: { burst: '◎', sustained: '○', attrition: '△' },
    distance: { min: 1600, core: 2000, max: 2400 },
    growthType: '普迟', temperamentLabel: '普通', heavyType: '普通',
    factors: [{ trait: 'burst', power: 1 }]
  }
}
```

- quality：真实繁殖素质，1–100；不读取旧 `game.breedingBase` 或 `breeding.strength` 自动冒充新赋值。后续迁移要显式制定映射。
- stability：产出能力波动的稳定度，1–100，不是竞赛发挥稳定度。常规模式不使用它改变基础能力。
- lineId：父系血系；familyId：母系家族。后代分别沿父系、母系记录，母马自身各项特点独立参与遗传。
- 因子每匹最多两项，各1或2级：瞬发、持久、消耗、草地、泥地、沉稳、重场。
- 未赋值素质/稳定度按50作为计算基准，明确提示未知；缺少的父母记录保持缺失。
- 校验重复编号、循环、已知父母性别、参数边界；数据不足不凭空补身份。

## 四代系谱与亲缘

以幼驹为起点，父母算第一代，共30个位置。保留每条路径显示重复，同时效果计算按祖先唯一编号去重，距离采用最近代数。

- 禁止直系交配（不限四代）以及共同祖先两侧分别不超过2代/3代的过近亲缘。
- 3×3允许但为高风险，3×4为中风险，4×4为低风险。多次重复按最高档处理，不无限叠加。
- 风险在生成时分别增加15%/10%/5%的暴躁覆盖机会，不扣基础能力；没有另造健康属性。
- 四代不完整时保留资料不足提示，不能声称没有近亲。
- 这是新框架规则；主席旧入口当前仍沿用旧近亲限制，切换时必须一起更新，不能混用。

## 四项配合理论

| 理论 | 第一版判定 | 效果 |
|---|---|---|
| 血系相性 | 父马血系与母父血系命中显式相性表 | 加强父母类型方向；主席能力计算额外+0.6，常规+0 |
| 祖先强化 | 四代内父母两侧共同祖先 | 该祖先因子影响乘1.5，受总上限约束；主席能力额外+0.4，常规+0 |
| 血统多样性 | 幼驹第三代8个位置全部已知血系，至少6种 | 类型方向权重向均衡靠近15%；主席能力额外+0.4，常规+0 |
| 祖先特征传递 | 四代内已明确赋值的祖先因子 | 父母至第四代按1、1/2、1/4、1/8衰减；每方向影响上限2 |

相性表是可替换的独立游戏配置，目前只有虚构示例，没有推断任何史实血系相性。所有主席理论能力奖励共用1.5上限；当前前三项全部成立时实际为1.4。

类型方向权重是1加父母对应等级分（◎2/○1/△0，未知1）及祖先因子。草泥因子每方向最多10%机会提升一级，沉稳/重场因子各最多10%机会带来相应特点。后代因子按合并后的方向独立抽取，随机保留最多两项，避免固定列表顺序偏向某一类型。第一版继承的因子均为1级。

## 两种模式的能力分布

常规：统一 `2d20+60`，范围62–100，理论均值81。父母素质、稳定度、配合理论均不改变这一分布。

主席：

```text
基础值 = 81 + (父母平均繁殖素质 - 50) × 0.18
波动 = (2d20 - 21) × (1.15 - 父母平均稳定度 × 0.006)
能力 = 四舍五入(基础值 + 波动 + 理论奖励)，限制在62–100
每次另有3%机会获得90–100的突破结果；取其与原结果较高者
```

突破、四舍五入和边界裁剪会影响最终实际均值，预览中的素质偏移不是最终期望值。高稳定度缩小波动，不保证每次更强；较弱血统仍保留顶级后代机会。

后代繁殖素质 = `50 + 0.65×(父母平均素质−50) + (2d16−17)`；稳定度使用0.6回归系数，均限制在1–100。两者不读取父母竞赛成绩或能力，公众评价也不能反向提高真实素质。无选择时回归中性，后续世界模拟通过选择繁殖个体形成竞争；尚未声称完成长期世界生态平衡。

## 其他遗传

- 草泥逐项40%父、40%母、20%新生成值，之后应用因子和现有草泥保底。
- 常规三类型保持现有七种组合的质量概率，只按父母/祖先权重分配优势方向。
- 主席三类型逐项40%父、40%母、20%方向候选值，使用现有组合约束投影；不自然产生◎◎◎。
- 距离整体区间、成长、气性、重场各自30%父、30%母、40%新生成值。距离区间整体继承，防止最短、最长、核心距离拼出无效区间。气性和重场独立抽取，不捆绑继承。
- 成长改变时同步生成对应巅峰区间；地区资料可以提供新生成值的场地和距离背景。三类型方向由本轮父母和祖先规则决定。

## 可调用接口与快照

```js
const library = Keiba.BloodlineSystem.createLibrary(records, nicks);
const pair = Keiba.BloodlineSystem.createPair(library, fatherId, motherId, 'normal');
const preview = pair.preview; // 不消耗随机数、不修改输入
const child = pair.generate({ seed: 20260923, childId: 'assigned-by-caller' });
```

模式可为 `normal` 或 `chairman`。可指定种子重现验证；不指定时使用现有随机流，方便主席年度冻结接入。个体ID由调用方分配，未提供则不生成ID。

生成结果保存规则版本、模式、父母遗传快照、四代位置、成立理论与风险。父母快照不嵌套其旧出生快照，防止代际存档指数膨胀。预览及结果不写存储；正式模式由现有保存/年度锁定流程负责持久化。该接口含真实遗传值，属于内部接口；正式UI必须由模式展示层决定公开范围。

## 本轮验收结果

53项测试通过，包含8项新增血统测试以及既有核心规则、主席配种、主席适性、语法与生产打包检查。

固定种子0–4999，各组5000匹；虚构父母除繁殖素质外其他特点相同：

| 模式 | 父母素质 | 后代平均能力 | 能力≥95比例 |
|---|---:|---:|---:|
| 常规 | 80/80 | 80.992 | 4.90% |
| 常规 | 20/20 | 80.992 | 4.90% |
| 主席 | 80/80 | 87.176 | 16.38% |
| 主席 | 20/20 | 76.690 | 1.48% |

结果验证了两种模式的目标差异，不代表参数已最终定案，也不代表多年世界模拟已经验收。
