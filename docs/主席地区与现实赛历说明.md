# 主席地区与现实参考赛历

适用范围：从新版创建入口建立的主席世界。世界内保存 `worldSystemVersion: 2`；没有该标记的存档继续使用原主席规则。普通、生涯及其他模式不载入这些地区资料。

## 开局与日常管理

- **现实参考世界**：选择日本、美国、英国、法国、爱尔兰、德国、意大利的任意组合。创建前预览已确认命名赛事、马场和初始现役规模。欧洲是上级分组，五国各自计算人口、赛历与地方奖项。美国与日本均不按州或城市拆人口。
- **空白新世界**：在赛历的地区管理中创建地区，再建马场和赛事、生成马群。至少有地区、马场、赛事和两匹现役马后才能推进。
- **地区管理**：修改名称、环境、人口、交通组、草泥比例、当地倾向和六类距离权重。现有马不重新生成；年度目标在后续年度补充与繁殖计划中使用。名称是显示内容，归属、行程、马场和地方奖项保留地区编号。
- **马场**：记录原名、中文名、别名、国家、行政区、城市、支持场地与赛道配置。纽马克特的 July Course 与 Rowley Mile 分开。适性仍使用原引擎维度，界面标明其映射。
- **完整赛历**：按年份、地区、马场、举办组、月份和级别筛选；命名赛事和条件赛均可查看。关注的赛事会进入首页。普通赛和条件赛保留完整赛果，人工赛事评分仍限 G1、G2、G3。
- **资料核对**：查看来源及暂未启用的赛事。玩家可为待核对赛事指定马场，记录为“玩家指定”，不会变成官方确认资料。

上述管理不要求开启世界编辑。普通马隐藏参数和单匹资格的直接改写仍使用世界编辑开关。

## 举办组与年度届次

育马者杯现有14场赛事属于同一举办组，默认按游戏年循环：

**Santa Anita → Del Mar → Keeneland → Santa Anita…**

三场的举办历史参考[育马者杯官方历史资料](https://stats.breederscup.com/bcosShowDocument.cfm?id=32)。循环顺序不代表现实年度计划。

JBC经典赛、JBC短途赛和JBC雌马经典赛也属于同一举办组，默认按游戏年在以下地方马场轮换：

**大井 → 船桥 → 川崎 → 盛冈 → 名古屋 → 佐贺 → 金泽 → 大井…**

三项赛事同届始终共用一座马场，候选顺序可在世界内调整。普通比赛库另保存现实届次举办地和已公布的距离覆写；主席世界的游戏年份不会冒充现实年份。

举办组与连冠挑战独立：前者安排场地，后者颁发连冠奖励。建立或导入举办组不会自行产生奖金、称号或能力奖励。

玩家可调整候选顺序、循环锚定年，或单独指定某一年；单年指定不推动循环。候选马场必须支持全部成员所需的草地或泥地。重复成员、跨组冲突、缺失马场、场地不支持均拒绝保存。

报名进入准备或连冠系列提前锁定时，同组该年度举办地一并冻结。冻结举办地不创建其他成员的报名名单，未锁定成员仍可编辑赛事定义。实际举行或取消时记录该届最终赛事快照。改名、改环境、调整候选和读档不移动已锁定举办地或过去赛果。

轮换保持赛事编号，不复制新赛事。日期、距离、奖金和资格不会随轮换场地自动改变。赛历、出马表、赛果、马场档案、举办组年度记录都使用年度举办地解析。

## 人口、遗传和交通

日本默认1000匹初始现役、250匹年度二岁马目标。其他地区按已确认启用命名赛事数×5，向上取4的倍数且不少于100匹；年度目标为四分之一。创建时可同时修改初始数量与年度目标，地区管理也可调整年度目标。自然出道不足时随机补足，超出时全部保留。

初始二至五岁马分组生成。日本二岁马为未胜利，三至五岁马均分初始资格；资格不伪造赛绩。草地／泥地／兼擅默认60／35／5，日本70／25／5。当地优势权重为1、1.5、2、3，只重新分配既有适性档位，不增加A／S数量或基础能力。

显式个体参数和被选中的父母属性优先于地区随机底稿。属性组仍按30%父、30%母、40%随机遗传。配种结算保存后代底稿、来源地区、生成配置及版本；已生成马和待出生参数不因后来编辑而重抽。

交通默认同地区0回合，同交通组不同地区1回合，不同组2回合。地区对可设置0～4回合并对称适用。交通准备与至少3回合出赛间隔同时满足，不相加；从实际所在地计划下一程。欧洲五国共用交通组，美国国内轮换不增加跨地区准备。

## 资格与排赛

日本使用未胜利、1胜、2胜、3胜、公开五级资格。新马限未出赛且未胜；未胜利赛允许未出赛者。赢得条件赛晋升一级，赢得 OP／L／重赏进入公开级。日本 OP／L／重赏至少需要1胜级，再检查年龄、性别。海外补充 OP 接纳新人，重赏要求实际胜利或初始参赛资格。

日本接入中央条件模板，另有成年未胜利出口，不叠加旧世界准备赛生成器。模板按需求开赛，少于两匹不开设；命名赛事少于两匹记录取消。同半月、资格、年龄、性别及场地兼容的未锁定不足额条件赛合并，目标8匹、上限16匹。

AI根据公开成绩、评价、公开的地区生成倾向和有限探索安排比赛，并照顾命名赛事供需。排赛不读取隐藏基础能力、真实距离范围或适性档位。已有连冠进度和锁定报名优先保留。整个六回合预排窗口会为不足两匹的命名赛事保留合法出赛者，避免其他赛事提前耗尽其可用马匹；不会拆散已经锁定的行程。

## 保存、分享与更新

完整存档为v9，内容包为v2；旧格式继续可读。新规则不会通过内容导入自动启用到旧世界；含新版举办体系的赛事包导入旧世界时明确拒绝。

单独导出轮换赛事会携带候选马场、举办组、轮换锚点、年度指定与锁定记录。后续导入同组其他成员按来源身份合并，重复导入复用对象。备份、恢复和另存为新游戏保持规则身份、轮换相位与冻结状态。

“检查资料包更新”先生成差异预览；玩家已修改的地区、马场、赛事和举办组保留。修改和更新只作用于当前世界，普通模式原始资料不变。未提供地区合并或历史级联删除。

## 本地验收入口

- `npm run test:quick`：常规规则、主席、资料、编辑、存储及新版地区单元回归。
- `npm run test:world:long`：日本与七地区组合，各5个固定种子、每个20年；输出逐地区逐年完成率、G1参赛数和半月耗时。
- `node scripts/audit-chairman-world-storage.js`：组合规模与20年合成历史的独立存储、查询、导出和备份恢复压力检查。
- `node scripts/check-chairman-world-storage-browser.js`：在真实 Chrome IndexedDB 中测量组合规模与20年合成历史的保存、查询、导出、恢复及半月增量保存；与模拟数据库的耗时分别记录。
- `npm run test:world:browser`：需可用 Playwright 与本地 Chrome；检查1440×900和390×844界面。
- `npm run build:web`：生成本地生产目录 `dist/`，不发布线上。

验收结果保存在 `artifacts/chairman-world-*.json` 与 `artifacts/world-browser.json`。生成分布报告使用每地区1万匹样本，另外比较中性与强烈当地权重，检查高适性数量和基础能力不变。长期模拟与合成历史压力数据分别标记，不能互相替代。
