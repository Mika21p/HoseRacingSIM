## 提交给新 agent 之前的检查

- 确认新 agent 所在目录确实包含移交包和快照列出的未提交成果；只有提示词没有文件不能完成交付。
- 停止旧 agent 对同一组文件的写入；可只读并行，但不能两个写入者同时改同一工作目录。
- 若跨机器，先完成经用户授权的检查点/文件备份与实验资料保留；不要只复制 worktree 的 .git 指针。
- 新 agent 无法使用某个客户端工具时，报告限制并选等价只读入口；不要因工具名不同改变业务范围。
