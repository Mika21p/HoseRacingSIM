状态：阶段 2 开发与功能验证完成，已写入本地、未发布。赛事覆盖仍有退步，全地区累计性能超过初始警戒线，尚未通过整体验收。

## 实现范围

### 声望数据与编辑

- 声望为 0～100 整数，0 是有效值；缺失、null 或编辑器留空采用来源默认／级别建议，小数、越界、字符串和非有限数在规则入口拒绝。
- 建议值：新马／未胜利 5、1 胜 12、2 胜 20、3 胜 28、OP 40、G3 55、G2 68、G1 80。级别修改不会强制覆盖既有声望，G2 可以高于 G1。
- 新增独立声望资料模块，以赛事来源 ID 关联。重点赛事有单独分值、设计依据、核对链接和日期；其余赛事明确标为按项目现有格付建议，未宣称全部经过逐场声望考证。
- 日本杯、有马纪念、东京优骏 98；凯旋门 100；代表性短途、泥地、牝马、长距离、两岁马路线均有单独设置。数值不是官方排名。
- 新建和编辑赛事支持声望，参考赛事支持世界内覆盖及恢复参考默认；预览、赛历、赛事档案和有快照的历史赛果展示声望。
- 新版赛事包与 CSV 复制、导入、导出保留声望；参考资料更新保留玩家覆盖。资料版本单独记录，避免同一举办地版本阻止声望更新。
- 已锁定和历史届次保持原快照；旧历史没有声望时显示未记录，不用今天的参考分追溯填充。
- 旧世界定义缺失声望时可直接读取默认值，常规同步补齐字段，不消费比赛、繁殖或排赛随机数，不重跑比赛。

### 目标、前哨与休整

- 目标观察未来 12 回合；实际报名保持未来 6 回合。远期条件补充赛不进入长窗口，限制计算量。
- 马匹先经过原有资格、休养、间隔、交通、系列和公开条件证据筛选，之后才比较声望。
- 依据公开评分／近期表现和已有资格区分积累经验、挑战升级、主攻荣誉。没有成绩的马使用已有资格定位，不读取隐藏能力。
- 同地区同年龄组（两岁／三岁／四岁以上）有至少 8 份公开评分时，至少出赛两次且处于前四分之一的马可主攻荣誉，达到组内第 40 百分位可挑战升级。参赛资格仍然独立检查；这一相对定位用于避免成年马绝对门槛压住当地幼马路线。
- 绝对阈值补充：公开参赛评分至少 110，或至少两份有效近期表现中位数达到 110，进入荣誉定位；公开评分或近期总体表现至少 95 可挑战升级。经验型倾向当前胜级／OP；挑战型根据资格和公开水平考虑 G3～G1。
- 声望每点对目标的贡献分别为 0.01／0.045／0.09；目标等待成本每回合 0.55，实际报名等待成本 1.4。目标窗口内增加 5 的目标报名优先，既有连冠追逐增加 20 并保留准备保护。
- 为匹配新增声望效用，将已有运输成本调整为准备回合 × 1.5，本土偏好为 2.5；没有新增年度出国上限或返乡规则。
- 可行的旧目标与当前最佳目标差距小于 2.5 时保留；失去资格、伤病、满额、赛历改变或明显更优目标可调整。
- 按公开参赛评分、奖金及固定偏好分配目标名额；满额转向合法目标，并显示落选备选。目标保留不是额外强制参赛名额，实际报名仍检查容量。
- 前哨要求在目标前，草泥一致、距离差不超过 400 米、无不利条件证据，并至少留下正常间隔和从前哨地到目标地的运输准备时间。不存在兼容前哨时可休整。
- 马匹档案显示主攻、升级、经验、前哨、复出、探索、落选备选或休整的实际安排原因。远征第二站和返乡计划仍属阶段 3。
- 审计额外记录每场因主目标准备而无法采用的候选数，把目标准备保护与资格／休养／运输不足分开。
- 保留阶段 1 的补位限制、锁定名单保护、同距离补充赛合并和稳定偏好，不靠声望绕开这些约束。

## 专项验证

- 最终全量快速回归：359 项全部通过，0 失败、0 跳过。
- 阶段 2 专项 13 项，覆盖边界值、编辑／恢复、包与 CSV 传递、参考更新保留覆盖并更新未覆盖值、多种子声望偏好、距离证据、前哨／休整、真实运输准备、落选备选、日历与伤病重排、幼马地区比较、默认 1,000 匹日本世界反复保存／重排、后台与前台规则一致。
- 编辑器交互通过 jsdom 验证实际表单的 0 值预览保存、恢复默认和小数拒绝；本轮未另做真实 Chrome 视觉验收，不把 DOM 测试等同于完整浏览器验收。
- 原有后台测试加载器补上 URL 查询参数处理，用于验证带缓存版本的真实 worker 入口。
- 一项旧排赛场景补充公开强马成绩，继续验证“更合适的大赛目标不被弱场补位吸走”；不再把没有成绩的一胜马预设成必然追逐 G1。
- 两个最终首年各含 24 次推进及年末结算，共 50 次审计开关一致性检查；规则违规为 0。
- 6 个固定场景审计回放一致；最终首年与固定场景源码指纹一致。
- 性能优化前后两组最终世界哈希一致；保持排赛、比赛及年末结果。
- 生产构建通过。

## 首年同配置对照与性能

最终行为对照采用种子 123、默认人口、完整首年及年末结算，与阶段 1 正式记录比较。下表是实际世界结果，非小场景推测。

| 指标 | 日本：阶段 1 → 阶段 2 | 全地区：阶段 1 → 阶段 2 |
|---|---|---|
| 命名赛事开赛 | 172/190 → 168/190 | 482/529 → 470/529 |
| 开赛率 | 90.53% → 88.42% | 91.12% → 88.85% |
| 重赏达到 6 匹场数 | 129/133 → 121/133 | 343/367 → 312/367 |
| 改签／可改签机会 | 29.20% → 23.93% | 45.42% → 37.41% |
| 目标与报名不足 3 回合间隔的累计冲突 | 11,606 → 0 | 37,703 → 0 |
| 海外出赛占比 | 0 → 0 | 39.58% → 33.11% |
| 跨交通组出赛占比 | 0 → 0 | 34.28% → 31.08% |
| 未开赛 G1 | 0 → 0 | 5 → 9 |
| 资格／休养／容量等审计违规 | 0 → 0 | 0 → 0 |

改签和间隔冲突为各回合累计事件，不是去重马匹数。目标与前哨不同本身不是问题，因此未把合法前哨计为错误。目标观察窗口由 6 扩至 12 回合，原始候选比较次数不宜直接横比。

**声望和目标机制功能通过，并不等于整体排赛效果已经达标。** 全地区取消 59 场（32 场 OP、13 场 G3、5 场 G2、9 场 G1）。取消主因分桶为：分配／赛程 24 场、目标准备保护 27 场、条件证据与其他约束 4 场、休养／运输／承诺 4 场。这是实际筛选过程的诊断，不是反事实因果证明。

阶段 1 提出的 5 场美国 G1 中，最终版香槟锦标恢复开赛；斯宾纳韦锦标、德尔马初登场锦标、费烈兹锦标、育马者未来锦标仍未开赛。最终另有圣雅尼塔德比、美国草地锦标、法国一千坚尼、叶森橡树、莫格莱尔牧场锦标未开赛。完整候选数和过滤原因保存在审计文件。

早期试跑发现绝对评级门槛压制当地幼马，加入地区年龄组比较后部分幼马赛事改善，但不能据此声称所有幼马 G1 已修复。新增声望还曾推高海外出赛，通过校准已有运输成本及本土偏好降至最终结果；完整远征生命周期仍待阶段 3。

后续联合校准必须同时关注重要赛事覆盖、国内路线供给、前哨与目标的时间竞争。不能为提高开赛率恢复强制调马，也不能直接把取消场次统称为马数不足。

| 正常半月耗时 | 阶段 1 中位数 / P95 | 阶段 2 中位数 / P95 | P95 对阶段 1 倍率 |
|---|---|---|---|
| 日本 | 248.4 / 285.4 ms | 288.5 / 326.8 ms | 1.14 |
| 全地区 | 835.1 / 1200.6 ms | 1029.6 / 1337.8 ms | 1.11 |

每组取 24 次正常半月推进，性能运行与测试分开顺序执行。全地区 P95 相对最初阶段 0 的 823.6 ms 为 **1.62 倍，仍超过 1.5 倍初始警戒线**；不能只用阶段 1 作为分母淡化累计成本。日本相对阶段 0 为 1.43 倍。

已将补位候选查询改为按届次索引、跳过报名窗口外的补位扫描，并将每匹马的定位和权重从逐候选计算移出。优化前后两组完整首年最终世界哈希完全一致。最后一项优化使全地区中位数略降，但 P95 没有改善，不能宣布性能问题已解决。

最终全地区全年审计约 144.7 秒（另有创建世界时间）；包含审计与正常推进双跑、检查点写入，RSS 同时包含两份世界。该工具测量并非浏览器交互或存档耗时。后续应继续分析长窗口候选规模、目标分配与内存回收，在扩增人口前复测；本轮未放宽警戒线。

## 已知边界

- 单种子首年对照不能证明所有地区和长期人口均达标，默认 NPC 数量和年度新马目标未改动。
- 声望资料第一版是代表赛事单独赋值加其余格付建议；可继续逐场精修，资料中会区分依据，不把建议分伪装成官方评价。
- 声望固定，不按当届阵容动态升降。
- 本轮目标路线不包含完整远征结束／返乡生命周期。
- 若重要赛事开赛覆盖仍不足，须结合各场合法候选、已承诺安排与公开路线分析，不能直接归因为总人口不足。
