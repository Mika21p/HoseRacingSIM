# 双倍人口与新马供给验证：运行前登记

按用户修正，人数合格门槛为：声望 ≥85 的 G1 至少 8 匹，其他命名赛（含低声望 G1）至少 5 匹。至少 2 匹可开赛不变。分地区分别要求开赛率 ≥95%、五匹组与八匹组各 ≥90%；没有八匹组记为不适用。取消场次保留在分母。

主实验：七个单地区与全部七地区组合，共八类；各地区开局现役数量和年度二岁马目标均为现有默认的两倍。种子 123，连续两年，即使首年未合格也继续，观察初始年龄结构退出后的情况。游戏排赛、资格、能力生成、赛历和声望保持阶段 3 版本不变；不修改正式默认值。

记录每季度二岁／三岁马的总数、已出赛、已获胜／具备资格、性别结构和二岁马比赛机会。每场不足人数的赛事另外记录：满足年龄性别的马、资格合格马、健康／间隔／运输可达马、已有其他承诺马。把二岁限定、三岁限定和其他比赛分开。

新马数量的对照：在日本和美国的双倍人口初始世界上，额外增加与该世界原有二岁马等量的二岁马，使二岁马翻倍、既有成年马不变，只跑首年。保存第一次排赛之前的共同初始世界，新增马使用正常生成、资格 0，不增加赛事、不提高能力、不授予胜利。两组额外对照不改变年度补充，故只用于检查首年新马总量假说，不代替长期年度补充试验。正常随机生成会消耗随机流，单种子结果只能作为干预线索，不声称完全隔离随机波动。

旧实验逐场记录可按新标准重新计数，但旧报告原判定不覆盖，不与新标准混用。报告给出单区与组合两套分地区结果，明确单种子两年不等于长期人口定稿。

## 补充诊断登记（主实验运行中，尚未运行此对照）

已观察到美国双倍人口仍有大量二岁马从未出赛，且补充赛仅有 2 岁以上公开赛。因此追加一组美国单区首年诊断：从同一排赛前初始世界出发，不增加马匹，每半月每草泥增加 1 场二岁未胜利补充赛，全年 48 场，距离按 1200／1600／2000／2400 米轮换，容量 16，使用现有未胜利资格与奖金规则。新增赛事均为按需补充赛，不进入命名赛合格率分母。此组只验证参赛／晋级出口假说，不修改正式赛历或默认规则，不作为人口方案正式通过的证据。
